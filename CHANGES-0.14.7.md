# Spectra 0.14.7 (Bedrock)

- Обновление последней версии: код WinGet 0x8A15002B («нет применимого обновления») больше не считается ошибкой — запускается установленная игра. При 0x8A150014 после `winget upgrade` автоматически пробуется `winget install` из Store.
- Старые версии / Windows 10 Edition: при конфликте идентичности пакета в диалоге добавлена кнопка «Заменить версию и запустить». Перед заменой миры копируются в bedrock/backups, затем старая версия удаляется с `-PreserveApplicationData` и ставится выбранная. Только для APPX/MSIX (UWP); MSIXVC (GDK) по-прежнему только скачивается.
- Одновременный запуск нескольких версий без замены не реализован: все они делят одну идентичность Windows и лицензию Store.
- Не проверено на реальной Windows (в среде сборки нет dotnet/Windows).
- В диалоге «Обновление через WinGet недоступно» добавлена кнопка «Открыть Microsoft Store».
- Диалог замены показывает предупреждение: замена удаляет установленный клиент Bedrock.
- Исправлено сравнение версий 0.15+ (0.16.0.5 = пакет 0.1600.5.0); «Показать ещё» справа как в Java; кнопки в диалоге замены разнесены.
- Замена версии: для пакетов из Store PreserveApplicationData недоступен (0x80073CFA). Теперь Spectra копирует всю com.mojang в bedrock/backups, удаляет пакет и возвращает данные после установки.
- Обновление последней версии: если WinGet вернул 0x8A150014, Spectra пробует публичный Store API (AppInstallManager.UpdateAppByPackageFamilyNameAsync) — это ближе к тому, что делает официальный лаунчер. Не проверено на Windows.
