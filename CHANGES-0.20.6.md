# Spectra 0.20.6

- Автоматическое получение временных Cloudflare TURN username/credential через сервер Spectra. Основной API-токен остаётся в Worker.
- Автоматический режим включён по умолчанию; прежний ручной список используется только при явном переключении в ручной режим.
- Поддерживаются массивы ICE URL, TURN UDP/TCP/TLS, проверка наличия username/credential до создания PeerConnection.
- Обновление временных данных до истечения срока и согласование ICE restart. Ответ на предложение той же сессии сохраняет существующий PeerConnection.
- При отсутствии настройки Worker доступен STUN и понятный статус. Нужны обновлённые сервер и оба лаунчера; инструкции в TURN-SETUP.md.

Проверены npm test сервера (15 тестов), npm test и test:dom лаунчера, сценарии кэширования/обновления TURN и сохранения PeerConnection при перезапуске ICE; синтаксис C#12. Реального TURN-ключа нет, поэтому выдача Cloudflare, связь двух удалённых компьютеров и полная сборка WPF не проверены. Сервер не развёрнут этим архивом. Установщик не изменён.
