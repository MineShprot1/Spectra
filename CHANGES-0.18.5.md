# Spectra 0.18.5

- Меню аккаунта: аватар, ник, пиктограммы действий, новая раскладка, анимация открытия и управление клавиатурой.
- Настройки: категории слева и одна открытая панель справа. Введённые значения сохраняются при переключении категорий; предупреждение о несохранённых параметрах Java при выходе остаётся.
- Экраны проверки обновлений, входа, приветствия и менеджера аккаунтов имеют общее оформление и компактный размер окна 600×470. Сверху доступны только пользовательские оконные кнопки. После успешного подключения окно возвращается к размеру библиотеки и проигрывает анимацию входа.
- У приветствия удалены отдельные фоны за ником, текстом и аватаром. Оконные кнопки менеджера доступны внутри диалога.
- Профиль: новая композиция шапки, превью, сведений, активности, сети и сохранённых скинов.
- Модель рук находится у сохранённых скинов. Смена ника доступна через карандаш рядом с ником и требует подтверждения «Да / Нет».
- Безымянная панель внешнего вида под превью. Плащи — компактные карточки с подписями снизу и выделением надетого. До 12 плащей размещаются по окружности, как циферблат; длинная коллекция — сеткой.
- Учитывается настройка уменьшенного движения.

Проверены Node-тесты, DOM-сценарии навигации/сохранения/подтверждения, синтаксис C# изменений размера окна и полная распаковка архива. Полная WPF-сборка и визуальная проверка на Windows в этой среде не выполнены. Сервер и установщик не изменены. Архив ZIP без сжатия; версия 0.18.5.
