# Spectra 0.17.1

- Страница завершения Google verification использует дизайн AuthPages.Success (страница Microsoft localhost): тот же CSS, встроенный пиксельный шрифт, логотип, фон, карточка и кнопка закрытия вкладки. Тексты относятся к Spectra Network. Ошибки используют этот же дизайн с состоянием bad. Динамические сообщения экранируются, close-tab script разрешён точным CSP hash.
- В друзьях убраны padding аватара-кнопки, изображение целиком вписывается в квадрат без обрезки.
- У кнопок управления окном убран отступ справа 6px.

Node-тесты проходят. Windows-сборка и визуальная проверка браузера недоступны в этом окружении. Для новой страницы Google нужен deploy обновлённого Worker; новых миграций нет.
