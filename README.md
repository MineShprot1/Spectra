# Пресеты градиента Spectra

Это отдельный патч оформления для исходников лаунчера 0.17.8/0.17.9. Чтобы сохранить ваш откат, полный архив лаунчера здесь не включён.

Скопируйте src/Spectra/Web/appearance.js поверх одноимённого файла в вашей папке исходников. При желании замените tests/appearance-tests.cjs для новых проверок. Затем соберите лаунчер обычным Build.ps1. Версия проекта и установщик не изменяются.

В настройках выберите тему «Градиент». Выберите элемент: фон, верхняя панель, нижняя панель или HUD (карточки, панели, окна, уведомления и быстрый запуск). У панелей и HUD можно отключить градиент или оставить «Как у фона»; ручное изменение цветов/направления создаёт собственный градиент элемента.

Введите название и нажмите «Сохранить пресет». Откройте «Пресеты градиента»: у каждого есть квадратное превью фона, имя, кнопка выбора и удаление. Пресет сохраняет фон и настройки всех трёх групп элементов. Можно сохранить до 50 пресетов. Выбор пресета не меняет язык, шрифты, CSS и расположение навигации.

Пресеты сохраняются в конфигурации лаунчера и остаются после перезапуска; экспорт/импорт JSON оформления также включает их. Сброс оформления сохраняет список пресетов. Интерфейс новых настроек переведён на все 13 языков.

Проверки: npm test прошёл. Проверены сохранение/восстановление пресетов через JSON, отдельные настройки элементов, выключение градиента, удаление пресетов и проверка входных данных. Сборка .NET и визуальная проверка WebView2 не выполнены в этой среде.
