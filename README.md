# Spectra 0.2.1 — исходники для Windows

Spectra — лаунчер Minecraft Java Edition на C# / .NET 8: WPF управляет окном, WebView2 рисует интерфейс Liquid Glass. Структура библиотеки и верхней навигации вдохновлена Steam; оформление, название и элементы — собственные.

**Это предварительная версия исходников, не проверенный готовый релиз.** В среде создания не было .NET SDK, Windows и Chromium. Компиляция C#, запуск игры, вход в аккаунт и сетевые установки здесь не выполнялись. Ниже отделены написанные возможности от оставшихся ограничений.

## Получить .exe без Visual Studio

1. Распакуйте архив. Содержимое папки `Spectra` загрузите в корень своего репозитория `MineShprot1/Spectra`, включая `.github`.
2. На GitHub откройте **Actions → Build Spectra for Windows → Run workflow**. Workflow также запускается при push в `main`.
3. После успешного выполнения скачайте артефакт **Spectra-windows-x64**, распакуйте его целиком и запустите `Spectra.exe`.
4. Нужен **Microsoft Edge WebView2 Runtime**. Он обычно есть на актуальной Windows; если отсутствует, установите его с официального сайта Microsoft.

Workflow собирает .NET вместе с программой: пользователю готовой сборки не нужно ставить .NET отдельно. Папка `Web` должна лежать рядом с `.exe`. Автопубликация релизов и загрузка файлов в ваш GitHub не выполнялись.

## Сборка на своём компьютере

Установите **.NET SDK 8 x64**, откройте PowerShell в папке проекта и выполните:

```powershell
powershell -ExecutionPolicy Bypass -File .\Build.ps1
```

Результат: `dist\Spectra\Spectra.exe`. IDE не обязательна. Для отладки:

```powershell
dotnet run --project src/Spectra/Spectra.csproj
```

## Первый вход и API

Стартовое компактное окно показывает статус обновлений: проверка пока отключена, как в задании. Затем предлагается вход Microsoft. Для просмотра библиотеки есть отдельная кнопка без входа; **игра без лицензионного аккаунта не запускается**.

Нажмите **«Войти с Microsoft»**: MSAL открывает официальную страницу Microsoft в браузере по умолчанию. Ответ возвращается через локальный callback `http://localhost`; ожидание ограничено пятью минутами. Пользователь не вводит Client ID или код устройства.

**В этом архиве регистрация приложения ещё не настроена:** `src/Spectra/microsoft-oauth.json` содержит пустой `clientId`. Разработчик должен зарегистрировать приложение Spectra в Microsoft Entra с личными Microsoft-аккаунтами и public/native redirect `http://localhost`, получить доступ Minecraft Services и вписать ID в этот файл перед сборкой. Секрет клиента не нужен. Без этого вход выдаёт объясняющую ошибку; автоматического переключения на встроенное окно нет. Нельзя использовать прежнюю конфигурацию провайдера как готовую регистрацию для другого redirect URI.

Кэш MSAL (`msal-browser.dat`) защищён Windows DPAPI; старый кэш встроенного входа не заменяет вход через браузер.

Для общего каталога с CurseForge укажите свой **CurseForge API key**. Для данных Crafty.gg — **Crafty API token**. Modrinth работает без ключа на этих публичных операциях. Если источник недоступен, интерфейс сообщает об этом; результат другого источника остаётся доступен. Запрет автора на сторонние скачивания CurseForge не обходится: установка выдаёт понятную ошибку.

Сессии Microsoft и токены Crafty/CurseForge хранятся с Windows DPAPI для текущего пользователя. Access token Minecraft не передаётся HTML-интерфейсу. Новый файл сессий — `microsoft-accounts.dat`; вход по старому `account.dat` не восстанавливается, потребуется войти повторно. Для браузерного входа требуется новая сессия MSAL. Активен последний успешно сохранённый аккаунт; интерфейс отдельного выбора сохранённых аккаунтов пока отсутствует. Выход очищает сохранённые сессии лаунчера.

| Окно | Кастомная рамка, перетаскивание через Win32 за свободную область верхней панели и название, двойной клик для разворачивания, начальный размер библиотеки до 1100×720 с учётом рабочей области монитора и DPI, изменение размера, свернуть/развернуть/закрыть, меню аккаунта |
| Визуальный стиль | Квадратные стеклянные панели, размытие, блочные блики, пиксельные SVG-иконки, собственный пиксельный шрифт с кириллицей, переходы и reduced-motion |
| Версии | Официальный полный манифест Mojang, поиск, обе сортировки, отдельные флаги snapshot/old_beta/old_alpha, карточки, создание сборки из версии |
| Картинки версий | Официальная лента Mojang Java Patch Notes; картинки размываются. Если у исторической версии нет изображения в ленте, остаётся нейтральный фон |
| Сборки | Создание и редактирование, название, иконка, баннер, отдельная `.minecraft`, быстрые кнопки папок |
| Загрузчики | Выбор совместимых Fabric/Quilt/Forge/NeoForge и версии; рекомендации/стабильные версии, установка профилей и библиотек |
| Запуск | CmlLib.Core устанавливает Minecraft и собирает процесс Java; повторный запуск сборки блокируется; остановка процесса |
| Логи | Автовыбор вкладки при запуске, stdout/stderr в реальном времени, ограничение буфера, выбор файлов logs, чтение `.gz` |
| Компоненты | Minecraft, LWJGL и mappings из метаданных, выбранный загрузчик; изменение версии через форму сборки |
| Моды | Файлы, Fabric/Quilt метаданные и иконки, включение/отключение через `.disabled` |
| Каталоги | Список из Modrinth и CurseForge, поиск, пагинация, фильтр версии Minecraft и загрузчика для модов, обязательные зависимости |
| Ресурс паки / шейдеры | Файлы, открытие папок, поиск и установка через оба каталога |
| Миры | Чтение имени и LastPlayed из `level.dat`, иконка `icon.png` |
| Серверы | Чтение списка и иконок из Java NBT `servers.dat` |
| Скриншоты | Сетка PNG/JPEG, имена, увеличение по нажатию |
| Настройки | Своя Java, автоустановка Eclipse Temurin/Adoptium по majorVersion официального манифеста, Xms/Xmx, размер окна, сворачивание |
| Графика | Предпочтение Windows для конкретного Java executable: энергосбережение/высокая производительность/выбор Windows |
| Обзор | Модпаки обоих источников, выделенная большая первая карточка, установка в сборки, локальный импорт `.mrpack` и CurseForge ZIP |
| Профиль | Смена Minecraft-ника, загрузка PNG-скина classic/slim, надеть доступный плащ или скрыть его через Minecraft Services, поиск другого игрока в Crafty |
| Общие параметры | Независимая копия настроек при создании новой сборки |

Скачивания используют HTTPS, временный файл и проверку контрольной суммы, если источник её предоставляет. Импорт архивов проверяет выход путей за папку сборки, число файлов и размер overrides. Модпаки устанавливаются в новую папку; при неудаче незавершённая сборка удаляется. Данные: `%LOCALAPPDATA%\Spectra`.

## Что ещё требуется перед готовым релизом

- **Проверить Windows build и все сетевые сценарии** с собственными ключами и лицензионным аккаунтом. Особенно старые Alpha/Beta, современные версии 26.x, загрузчики и разные модпаки: поддержку библиотеки нельзя считать проверкой каждой версии.
- **Точный GPU для каждого режима:** сейчас показывается список адаптеров, а режим записывается в Windows. Определение конкретного адаптера по DXGI GPU preference ещё не реализовано. Windows может переопределить предпочтение; оно также общее для сборок, использующих один и тот же Java executable.
- **Профиль Crafty:** данные сейчас выводятся читаемым JSON, а не полным оформленным профилем Steam. Смена игрового профиля подключена к Minecraft Services; для неё действуют серверные ограничения. Аватар пока отображается как инициалы.
- **Полные метаданные локальных дополнений:** Forge/NeoForge TOML, shader/resource pack описания, поддерживаемые версии и иконки всех форматов ещё не разбираются; имя файла остаётся резервным отображением.
- **Редактор компонентов** сейчас показывает реальные компоненты и меняет версию. Произвольные операции с LWJGL/JAR/Java agents и перестановка компонентов со скриншота не реализованы.
- **Steam-подобная витрина:** есть выделенная карточка и карточки каталога, но нет карусели редакционных подборок и страниц подробностей проекта.
- **Загрузка:** нет кнопки отмены, очереди с восстановлением, лимита скорости и транзакционного отката установки отдельных дополнений в существующую сборку. Modrinth optional dependencies пока не предлагаются отдельно. При проблеме модпака с запрещёнными файлами CurseForge требуется ручная установка.
- **Оптимизация:** сетевые операции асинхронные, изображения lazy, список версий порционный, лог ограничен. Полноценные измерения CPU/RAM/времени запуска пока не проведены; постоянный офлайн-кэш каталогов и общие игровые assets ещё не сделаны.
- **Серверы:** Vanilla не записывает историю последнего посещения в `servers.dat`; показывать выдуманную дату нельзя. Редактирование серверов и отслеживание посещений ещё не добавлены.
- **Обновления:** проверка/установка релизов GitHub, подпись `.exe`, инсталлятор и восстановление после повреждённого config ещё впереди.

## Проверки

В текущей среде выполнены:

- `node --check src/Spectra/Web/app.js` — прошёл;
- `node tests/frontend-tests.cjs` — прошёл: экранирование контента, проверка image URL, запрет имитации запуска/входа в браузерном preview, ответы RPC, ограничение лог-буфера;
- XML-проверка проектов и XAML — выполняется при подготовке архива.

**Не выполнены здесь:** `dotnet build`, C# тесты, UI smoke в Chromium, вход Microsoft, установки и реальная игра. Workflow включает эти локально доступные проверки: C# build, девять core проверок (пути, память, сериализация, NBT), UI smoke (навигация, фильтры, создание, вкладки, настройки, компактный размер) и публикацию Windows x64. Вход и запуск игры нужно проверить вручную. UI smoke сохраняет скриншоты в отдельный GitHub artifact.

Для просмотра только интерфейса откройте `src/Spectra/Web/index.html` в браузере. С параметром `?sample=1` видны две демонстрационные сборки. Preview явно не запускает игру и не входит в аккаунт.
