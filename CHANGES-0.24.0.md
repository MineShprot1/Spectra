# Spectra 0.24.0

- Все штатные иконки перерисованы на сетке 16 × 16 без скруглённых штрихов. Старые настройки контурных и скруглённых наборов переводятся на пиксельные; загруженные пользователем PNG остаются сохранены.
- Друзья снова открываются панелью внутри лаунчера, в том числе по команде из трея. Отдельное окно и его ресурсы удалены.
- Блок аватара и ника, уведомления, индикатор масштаба, чат, переключатели, предпросмотры и новые карточки используют квадратные рамки и шрифты Spectra. Темы меняют палитру, сохраняя общий пиксельный язык интерфейса.
- Исправлена светлая палитра «Спектры» и приоритет CSS-переменных: прежние стили отдельных тем больше не подменяют выбранный режим тёмными цветами. Перепроверены фон, панели, навигация, поля и текст во всех 14 светлых/тёмных режимах. Нативные уведомления также учитывают режим и цвета темы.
- Оставлен один выбор языка, рядом с ним — флажок выбранного языка. Удалены второй список и повторяющийся блок названия.
- «Обзор» получил единый магазин для Java и Bedrock: категории сбоку, поиск, переключаемую витрину со скриншотами проектов, горизонтальные подборки, каталог и блок переходов между категориями. Для Java модов, модпаков, ресурсов и шейдеров есть рейтинг по загрузкам; категории без опубликованной статистики не показывают вымышленные показатели.
- Карусель автоматически переключается раз в семь секунд, останавливаясь при взаимодействии и при скрытом окне; системное уменьшение анимации отключает автоматическое переключение. Метаданные галерей кэшируются с ограничением размера.
- Одинаковые проекты из Modrinth и CurseForge объединяются в одну карточку. Доступные источники остаются в переключателе загрузки, правильные ID передаются в установку. Проверяются названия, авторы и slug; разные проекты одного сервиса и несовпадающие авторы с разными slug сохраняются отдельно. Поддержаны короткие названия и суффиксы-акронимы наподобие «Just Enough Items (JEI)».
- Объединение работает и при подгрузке следующих страниц. Выбранный источник сохраняется после подгрузки, показатели загрузок разных площадок не суммируются.
- Быстрый запуск не перекрывает витрину и категории магазина. При обновлении версии один раз очищается дисковый кэш веб-интерфейса без удаления аккаунтов и cookies, чтобы старые ресурсы не подменяли новый интерфейс.

Проверено автоматическими тестами нативного кода, DOM и Chromium: цветовые режимы, пиксельные элементы, единственный список языков, панель друзей, карусель, галереи, подборки, категории Java/Bedrock, пагинация и выбор источника установки. Подробные скриншоты проверки находятся в `test-results/024-*.png`.
