# Spectra 0.23.0

- Обновлён первый запуск: анимация приветствия, выбор оформления с предпросмотром и светлым режимом. Анимации учитывают системное уменьшение движения.
- Тёмная и светлая темы объединены в «Спектра». Старые настройки и JSON темы мигрируют автоматически. У каждой темы, кроме Gradient и Modern, сохраняется собственный светлый/тёмный режим.
- В настройках появились визуальные карточки тем, схемы расположения навигации и локальные флажки 19 языков. Обновлены основные иконки, блок профиля и расположение кнопок сборок.
- «Обзор» получил витрину в духе Steam с выделенной сборкой из результатов каталога. Оформление следует выбранной теме Spectra.
- Список друзей открывается отдельным окном Windows с поиском, запросами, добавлением друзей и переходами к чату/группе. Шифрование и доставка сообщений выполняются только основным окном.
- Чат показывает аватарки с резервным изображением, поддерживает **жирный**, *курсив*, ~~зачёркивание~~, `код` и эмодзи. Форматирование экранирует HTML. Опросы без новых данных не пересоздают поле ввода; сохраняются черновик и выделение.
- Всплывающие уведомления стали компактнее. В трее добавлены библиотека, версии, друзья, запуск выбранной сборки, папка Spectra, настройки и переключение уведомлений. Меню учитывает светлый/тёмный режим.
- Добавлены настройки перехода в редактор при запуске, полного скрытия быстрого запуска и уведомлений: общий выключатель, системные окна со звуком, запуск игры друзьями, личные чаты и группы.
- Ctrl + колесо изменяет сохранённый масштаб настроек шагом 5%, в пределах 65–150%, с кратким индикатором. Встроенный независимый масштаб WebView отключён.
- Во всех шести категориях файлов есть «Выбрать всё» и массовое удаление; локальные файлы отправляются в корзину. Моды, шейдеры и ресурсы можно удалять по одному. Поиск и выбор сохраняются при обновлениях списка.
- Исправлена обработка повреждённых ZIP/JAR (`End of Central Directory`). Один повреждённый мод больше не прерывает весь список. Добавлено чтение иконок Forge, NeoForge, Quilt, старого Forge и resource pack; повреждённые архивы предпросмотра удаляются из кэша.
- Одинаковые иконки дополнений хранятся одним PNG в дисковом кэше и передаются в интерфейс URL вместо повторяющихся base64. Кэш метаданных версий ограничен. Неизменившийся чат не перерисовывается.
- Minecraft assets и Java уже использовали общие каталоги; теперь библиотеки тоже общие. Существующие JAR библиотек переносятся в общий кэш копированием один раз, без удаления оригиналов. У сборок остаются отдельные моды, настройки, миры и версии загрузчиков.
- Bedrock распаковывается во временную папку с проверкой путей и ограничением размера, затем целиком переносится на место. Ошибки не оставляют частичную установку. Пакеты и квитанции попытки установки очищаются; явная команда «Скачать пакет» сохраняет пакет. Старые временные файлы очищаются отдельно от пользовательских данных и готовых пакетов.
- Изучены `Downloaders/VersionDownloader.cs` и обработка пакетов GDK в [BedrockLauncher, ветка lite](https://github.com/BedrockLauncher/BedrockLauncher/tree/lite). Сторонний код не копировался. GDK устанавливается через Minecraft Launcher / Microsoft Store; неподдерживаемая прямая установка останавливается до загрузки большого пакета.

## Проверки

Нативные тесты проверяют повреждённые моды, метаданные и иконки разных загрузчиков, общий кэш библиотек, сохранение настроек, защиту удаления и атомарную распаковку Bedrock. Проверки Chromium покрывают карточки и режимы тем, флажки, масштаб, массовые операции, сохранение поиска, закрытие по фону, первый запуск, отдельное окно друзей и форматирование чатов.

Настоящие установки Minecraft, авторизация и обмен сообщениями с другим устройством требуют проверки с аккаунтами и сетью. Снижение потребления оперативной памяти в мегабайтах не измерялось.
