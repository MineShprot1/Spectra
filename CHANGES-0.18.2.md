# Spectra 0.18.2

- При завершении с кодом 0 кнопка «Спросить ИИ» не показывается; предыдущая кнопка удаляется. При ненулевом коде диагностика остаётся доступной.
- Удалена дополнительная боковая библиотека Steam. Основная область занимает всю ширину; быстрый запуск остаётся справа. Переработаны цвета, типографика, вкладки, поля, диалоги и кнопки под настольный Steam.
- Новая тема Modern: мягкий фиолетово-мятный фон, градиентные акценты и округлые карточки.
- Новая тема Liquid Glass: светлое оформление в стиле iOS, прозрачные панели, стеклянные меню, округлые кнопки и сгруппированные элементы. Размытие используется на небольших панелях, а не на каждой карточке.
- В Windows 11, Steam и Frutiger Aero доступна настройка иконок: пиксельные, контурные, скруглённые. Каждую из 17 основных иконок можно заменить PNG с прозрачностью до 8 КиБ. Общий лимит пользовательских изображений — 32 тыс. символов base64. Настройки отдельные для каждой темы, входят в JSON экспорта.

Сервер и установщик не изменены. Обновлять Worker для этой версии не нужно.

Проверки: Node-тесты и DOM-сценарии, включая код завершения 0, переключение новых тем, сохранение стиля иконок и отсутствие боковой библиотеки Steam. Полная WPF-сборка и визуальная проверка в Windows не выполнены в этой среде.
