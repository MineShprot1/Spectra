# Spectra 0.27.1

- Кнопка закрытия чата перенесена в саму шапку: она больше не перекрывается её слоем. Закрытие и приглашение имеют одинаковую область нажатия 32×32; у приглашения — иконка человека с плюсом, с пиксельным и гладкими вариантами для соответствующих тем.
- Проверка обновлений работает в отдельном нативном цикле раз в две минуты, независимо от JavaScript, открытого окна, сворачивания и трея. Временная ошибка не останавливает последующие проверки. Состояние обновления внизу окна обновляется независимо от настройки уведомлений.
- Исправлено подавление первого найденного обновления после неудачной проверки. Пока окно активно, обновление предлагается внутри лаунчера; в фоне используется настольное уведомление с учётом настроек. Повторные уведомления об одном коммите подавляются.
- Найденное при запуске обновление устанавливается автоматически до входа в аккаунт, приветствия и библиотеки. Это относится и к первому, и к фоновому запуску. Дополнительного вопроса об установке нет.
- Ошибка проверки больше не считается отсутствием обновлений. Показываются причина и «Повторить»; продолжить со старой версией можно только явной кнопкой. Если стартовая проверка не удалась из-за сети, успешная фоновая проверка возобновляет подготовку автоматически.
- После сбоя установки нет тихого перехода в библиотеку. Перезапуск после отката помечается режимом восстановления, чтобы не зациклить установку. Сохранён фоновый режим при перезапуске после обновления.
- Исправлена запись метки установленного коммита при наличии нескольких установок Git. При отсутствии файла метки используется SHA из метаданных сборки. Старый файл ошибки не блокирует автоматическое обновление навсегда.
- Добавлены проверки первого/фонового запуска, ошибок сети и GitHub, повторной попытки, восстановления после отката, фонового цикла и настоящего нажатия закрытия чата во всех темах. Дополнены языковые пакеты.
