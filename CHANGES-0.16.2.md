# Spectra 0.16.2

- Удалены Planet Minecraft, Nova Skin и Minecraft Inside из источников.
- NameMC и Skindex доступны для скинов Java и Bedrock.
- Добавлен адаптер NameMC через Parse: популярные скины и скины по нику игрока. Отдельный ключ Parse сохраняется через настройки, защищён DPAPI и не передаётся в состояние WebView. Без ключа доступен браузерный каталог. PNG скачивается через прежний проверенный адаптер страницы или вручную с импортом, если сайт блокирует HTTP.
- Повреждённая или устаревшая запись активности друга больше не ломает список. В generic ошибке сервера виден путь запроса.

## Ограничения

MineSkin не является API каталога Skindex. Переданный ключ MineSkin не встроен в исходники, поскольку для поиска Skindex он не подходит.
Ссылка Minecraft Maps rpc-api-explorer описывает управление игровым сервером, не каталог карт. Каталог оставлен с браузерным чтением и ручным импортом.
Репозиторий terastudio-org/mcpedl — Node.js библиотека для mcpedl.org (по README), не готовый HTTP API для используемого mcpedl.com. Исходники src не удалось получить; неподтверждённые маршруты API не добавлялись. MCPEDL оставлен с браузерным чтением и импортом.

Конкретная причина инцидента 15e606d8-e870-49bc-9699-89755fc2d71a неизвестна без журнала Worker. Исправление повреждённых presence-записей покрыто тестом, но не подтверждено как причина этого инцидента.

Node-тесты лаунчера и сервера проходят. C#/WPF сборка, реальные API и Windows WebView2 не проверены в Linux окружении без dotnet. Новый NameMC адаптер нуждается в проверке с действующим ключом Parse.
