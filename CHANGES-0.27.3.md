# Spectra 0.27.3

- Исправлен размер библиотеки после запуска с `--background`: после проверки обновлений вызывается то же нативное расширение окна, что и при обычном запуске, до восстановления аккаунта. При открытии из трея или повторном запуске ярлыка библиотека получает обычный размер вместо 600×470.
- Расширение окна не вызывает его показ и активацию: фоновый запуск остаётся фоновым. Экран проверки обновлений сохраняет компактный размер.
- Добавлена проверка настоящего пути завершения фонового запуска при успешном и неудачном восстановлении аккаунта: расширение выполняется после проверки обновлений и до открытия библиотеки.
