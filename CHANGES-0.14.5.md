# Spectra 0.14.5

В каталогах Java и Bedrock добавлен отдельный раздел «Установленные версии» над основным списком. Раздел можно свернуть; состояние хранится отдельно для двух изданий. Карточки установленных версий исключаются из основного каталога, доступны выбор и запуск. Длинные списки показываются порциями по 24.

Java: проверяется наличие непустого client JAR и JSON версии в каталогах сборок Spectra. Это наличие основных файлов версии, а не проверка всех библиотек, ресурсов и Java runtime; запуск при необходимости доскачает недостающие компоненты. В разделе показываются установленные идентификаторы из официального каталога. Клиенты, лежащие вне папки данных Spectra, не сканируются.

Bedrock: установленные приложения берутся из зарегистрированных пакетов и ярлыков Windows. Скачанный архив не считается установленной игрой. Он по-прежнему не является независимым исполняемым клиентом. При конфликте с текущей игрой Spectra предлагает только скачивание и объясняет ограничение; последний установленный клиент не заменяется историческим пакетом.

«Последняя версия» получает кнопку «Обновить», когда известный номер обычного установленного пакета меньше номера последнего стабильного выпуска каталога. Preview не влияет на сравнение. Старая Windows 10 Edition тоже считается установленной и получает предложение обновить обычную игру. Неизвестный номер из Get-StartApps не трактуется как устаревший.

Обновление после подтверждения использует winget upgrade с точным продуктом Minecraft и источником msstore, прогрессом и логом в Spectra. WinGet / Store определяет реально доступное обновление для аккаунта; отсутствие обновления или отказ сервиса показываются как ошибка с кодом, без обещания успеха. Каталог метаданных может отставать или содержать выпуск, ещё недоступный конкретному аккаунту. Только действие «Последняя версия / Обновить» разрешает обновить обычную системную игру; установка исторических выпусков сохраняет запрет замены.

Проверено: компиляция всех C# исходников, 15 основных тестов, проверки выбора и сравнения версий, аргументы команды upgrade, DOM разделов Java / Bedrock, сохранения сворачивания и кнопки обновления. Реальная работа WinGet и запуск игры на Windows здесь не проверены.
