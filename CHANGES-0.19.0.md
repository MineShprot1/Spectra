# Spectra 0.19.0

- Исправлено соотношение сторон превью плащей: canvas больше не сплющивается.
- Постоянные Party-группы с приглашениями, предупреждением об IP, ролями, передачей владельца и отключением P2P без выхода из группы.
- WebRTC DataChannel между участниками и локальный TCP-мост для удалённых Java LAN-миров. Список миров с метаданными и реальным player count при доступном status ping.
- Отдельная P2P-передача сборки выбранного LAN-мира: выбор файлов, отдельная установка и SHA-256.
- Экспериментальные личные и групповые E2EE-чаты на libsodium, ручная сверка ключей, локальное DPAPI-хранилище, офлайн-почта и mute.
- Кликабельные приглашения на серверы и в LAN/Party.
- Работа в системном трее после закрытия окна, отдельные анимированные уведомления с предоставленным звуком.
- Новая миграция сервера `0006_party_chat.sql`; deploy автоматически применяет миграции перед публикацией.

Порядок установки, проверки и существенные ограничения перечислены в **PARTY-0.19.0.md**. Это экспериментальная сетевая версия; независимый аудит и проверка двух Windows-клиентов не выполнены. Установщик не изменён.
