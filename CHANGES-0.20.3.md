# Spectra 0.20.3

- Проверка Ed25519-подписи v1 больше не зависит от порядка полей заголовка после передачи через JSON. Используется исходный порядок полей протокола, с совместимостью с прежним порядком полученного заголовка. Значения полей, получатель, подпись и зашифрованный заголовок продолжают проверяться. Регрессионные тесты проверяют обратный и алфавитный порядок, а также подмену значений и подписи. Это исправляет воспроизведённый случай отказа подписи после перестановки полей; точный маршрут преобразования JSON у друга по скриншоту определить невозможно.
- Новое настольное уведомление: прямоугольная пиксельная рамка, шрифт из ресурсов лаунчера, фирменная кнопка, полоска времени, пауза при наведении. Сохраняются звук, очередь и переход по уведомлению. Убрана прозрачная поверхность окна; анимации учитывают настройку Windows.
- При обнаружении обновления предлагаются «Обновить» и «Отмена». Закрытие окна откладывает установку, кнопка внизу лаунчера остаётся доступна. Ручная кнопка также запрашивает подтверждение. Фоновый запуск не показывает это окно.

Обновите оба лаунчера и проверьте новые личные и групповые сообщения. Сообщения, которые прежняя версия уже отклонила и подтвердила серверу, нужно отправить повторно. Ключи не сбрасываются и защита от подмены не отключается. Изменения сервера и установщика не требуются.

Проверено: npm test, npm run test:dom (включая подтверждение/отмену/закрытие предложения обновления), реальное libsodium, C#12 syntax и компиляция Windows-хелперов с Windows Desktop references. Полная сборка WPF и визуальная проверка нативного уведомления на Windows не выполнялись.
