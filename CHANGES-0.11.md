# Spectra 0.11 — друзья и сборки

## Интерфейс друзей

- Панель поверх библиотеки, плавное открытие и закрытие через transform/opacity, поддержка уменьшения анимаций Windows.
- Поиск по имени, друзья в сети в начале списка, счётчик онлайна, индикаторы статуса, ограниченная прокрутка списка.
- В собственном профиле два независимых переключателя: скрыть сетевой статус и скрыть игровую активность. Скрытие сети также скрывает игру.
- Worker удаляет закрытые сведения из ответов и запрещает доступ к файлам скрытой сборки. Обновить нужно и клиент, и Worker.

## Подключение к другу

- Сравниваются Minecraft, загрузчик, его версия и SHA-256 всех **включённых** модов. Название модпака, имена файлов и источник каталога не заменяют сравнение содержимого.
- Если подходящая сборка найдена, можно сразу подключиться. Иначе можно создать новую сборку или заменить любую незапущенную сборку.
- Категории «Моды», «Шейдеры», «Ресурс паки»; по умолчанию включены только моды. Каждую категорию можно раскрыть и снять галочки с отдельных файлов.
- Заменяются только выбранные категории целиком. Даже пустой выбранный список означает очистку этой категории. Старые папки и сведения сборки сохраняются в `<папка сборки>/backups/friend-…`.
- Загрузка сначала выполняется во временную папку. Размеры и контрольные суммы проверяются до замены; обычная ошибка замены возвращает прежние папки. Это обработка ошибок, а не гарантия восстановления после отключения питания.
- После установки предлагается добавить адрес сервера в servers.dat; одинаковый адрес повторно не добавляется.
- Если вы сознательно убрали моды, можно сразу подключиться с выбранным составом. Сервер всё равно может потребовать отсутствующие моды. Исключение действует только для только что установленной сборки, пока её моды не изменились, и не дольше часа.
- LAN по-прежнему требует общей локальной сети; публикуется адрес, вручную указанный после «Открыть для сети».

## Передача файлов

Нужен обновлённый Worker и закрытый R2 bucket с привязкой PACKS; инструкция — в отдельном архиве сервера. Лаунчер публикует файлы при запуске Minecraft, если аккаунт Spectra подключён и игровая активность открыта. Первая передача может занять время; до её завершения сборка не доступна для установки.

Передаются только включённые `.jar` из mods и `.zip` из shaderpacks/resourcepacks. Миры, скриншоты, config модов, options.txt, учётные записи, Java и настройки компьютера не передаются. Поэтому это перенос состава дополнений, а не полный экспорт каталога .minecraft. Папки-ссылки и файлы-ссылки не поддерживаются.

Лимиты: 64 МиБ на файл, 512 МиБ на сборку, 2000 файлов; на сервере 2 ГиБ загрузок в сутки на аккаунт. Неактивные опубликованные сборки очищаются через 7 дней. R2 не следует открывать через публичный r2.dev: доступ обеспечивает Worker только принятым друзьям с активной открытой игрой.

Список сборки учитывает файлы, добавленные вручную, а не только каталог Modrinth/CurseForge. Для большего модпака нужно повысить согласованные лимиты клиента и сервера; в этой версии такой пакет не публикуется, но сама игра запускается как прежде.

## Библиотеки модов

- Рекурсивно устанавливаются обязательные зависимости: Modrinth required и CurseForge RequiredDependency.
- Для Modrinth учитываются точные version_id, проверяются Minecraft и загрузчик, обнаруживаются конфликтующие требования к одной библиотеке и циклы.
- Совместимая уже установленная библиотека выбирается без повторной загрузки; отключённый файл с подходящей суммой включается.
- Необязательные зависимости не устанавливаются автоматически. Неописанные в API и только вручную доступные библиотеки автоматически найти нельзя.
- Файлы заранее скачиваются и проверяются во временной папке. При ошибке применения возвращается прежнее состояние. Установка дополнений и замена/запуск сборки не выполняются одновременно.
- Хеши локальных файлов кешируются по пути, размеру и времени изменения.

## Проверено

Node: frontend-tests, appearance-tests, skin-tests, friends-tests; пять тестов Worker на настоящем SQLite с имитацией R2 и ответов Google. Проверены доступ только друзьям, скрытый статус, контрольные суммы, выбор категорий и добавление сервера.

В этой среде нет .NET SDK, Windows и Chromium: компиляция C#, реальные анимации WebView2, R2 и Google OAuth после деплоя здесь не проверены. Для проверки Windows используйте Build.ps1 и реальные аккаунты на обновлённом Worker.
