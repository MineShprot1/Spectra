# Сборка и проверка на Windows

Нужны Windows 10/11, .NET SDK 8, WebView2 Runtime. В корне лаунчера запустите `powershell -ExecutionPolicy Bypass -File .\Build.ps1`. Готовый EXE будет в `dist\Spectra\Spectra.exe`. Для инсталлятора есть `BuildInstaller.ps1`. Серверный архив обновите по его README перед проверкой друзей.

Проверки перед выпуском:

1. ВЕРСИИ: скачать отсутствующую Java-версию. Игра не запускается, кнопка меняется на ИГРАТЬ. Запустить её, закрыть, удалить; миры и пользовательские сборки остаются.
2. Bedrock: при наличии обновления нажать Обновить. Проверить установленный и отсутствующий официальный Launcher, а также выбор Minecraft for Windows. Проверить новую и старую упаковку клиента отдельно.
3. Развернуть окно на мониторах с разным DPI и положением панели задач. Панель задач остаётся доступной. F11 включает/выключает полный экран; кнопка настроек делает то же. Проверить перезапуск с сохранённой настройкой.
4. Открыть предупреждения и выбор модов: клавиатура, Escape, прокрутка, длинные имена. Повернуть скин, отпустить мышь вне области, сменить несколько скинов подряд. Проверить две стороны плаща.
5. ОБЗОР: пройти все категории/источники; проверить прямую загрузку и ручной импорт. Java-скин появляется в профиле, Bedrock PNG — в выбранной папке. Карта ZIP должна успешно открываться в выбранной сборке/версии.
6. Bedrock: импортировать .mcworld/.mcpack/.mcaddon, запустить последнюю версию, дождаться импорта в игре. Проверить списки ДОПОЛНЕНИЯ из UWP и GDK. Закрыть игру и проверить удаление с резервной копией. Удалить также файл Spectra, если не нужен повторный импорт.
7. Два Minecraft-аккаунта с лицензиями: перенести старые сессии друзей и проверить сохранение отношений, запросы, приватность и передачу сборок. У Vanilla нет скачивания сборки, подключение работает. Без лицензии вход в сеть должен отклоняться.

Для JavaScript: `npm test`; дополнительно после `npm install` — `npm run test:ui` и `npm run test:dom`. Они требуют Playwright/Chromium и jsdom соответственно. Эти дополнительные проверки не выполнены при подготовке архива.
