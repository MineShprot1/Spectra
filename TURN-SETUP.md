# Автоматический Cloudflare TURN — Spectra 0.20.6

Сначала установите новый сервер и лаунчер у обоих игроков. Обновлять установщик не требуется.

1. В панели Cloudflare откройте Realtime → TURN и создайте TURN key. Сохраните его ID и API token. Это отдельные данные, не Google Client Secret и не токен входа игрока.
2. В папке этого сервера откройте терминал Windows и выполните:

```powershell
npm.cmd install
npx.cmd wrangler secret put TURN_KEY_ID
npx.cmd wrangler secret put TURN_KEY_API_TOKEN
npm.cmd run deploy
```

После каждой команды `secret put` вставьте соответствующее значение в запрос Wrangler. Не вставляйте основной API-токен в ICE JSON лаунчера и не добавляйте его в исходники.

3. В лаунчере откройте группу → «Настройки соединения». Оставьте включённым «Автоматически получать TURN от Spectra», нажмите «Сохранить». Сделайте это у обоих участников. При обновлении автоматический режим включён по умолчанию и игнорирует старый ручной список, пока вы явно не выберете ручной режим.
4. Подключитесь к Party. Лаунчер получит временные username/credential через авторизованный `/social/ice`. Прямое соединение остаётся предпочтительным; TURN доступен как запасной маршрут. Наличие TURN-данных не означает, что выбран именно relay-маршрут.

## Как это работает

Worker выдаёт данные только авторизованным участникам группы с включённым подключением. При отсутствии обоих секретов возвращается STUN и явное сообщение, что TURN не настроен. При частичной настройке или отказе Cloudflare возвращается понятная ошибка.

Временные данные живут час. Они кэшируются на игрока в памяти Worker, ограничены дополнительным лимитом 4 выдачи в минуту на пользователя через D1. Лаунчер хранит автоматически полученные данные только в памяти и запрашивает обновление до истечения срока. Настройки существующих PeerConnection обновляются; согласование ICE restart выполняется без намеренного пересоздания канала. Перерыв передачи при смене маршрута всё же возможен.

API-токен остаётся только в secrets Worker. Неактивное членство блокирует получение новых данных, но уже выданные временные данные действуют до срока истечения. Лимит запросов не ограничивает объём relay-трафика: настройте наблюдение за расходами в Cloudflare.

Cloudflare TURN — отдельный тарифицируемый сервис. Ознакомьтесь с условиями в вашей панели перед использованием: https://developers.cloudflare.com/realtime/turn/

Документация API: https://developers.cloudflare.com/realtime/turn/generate-credentials/

## Проверка и ограничения

Автотесты проверяют членство, запрос Cloudflare, кэш, истечение срока, ошибки без утечки секретов, ограничения выдачи, формат ICE, обновление PeerConnection и согласование перезапуска ICE. Настоящие TURN-ключи не предоставлены, поэтому реальная выдача Cloudflare и игра через relay не проверены. Эта поставка готовит код и инструкции; без выполнения настройки выше TURN не включится.
