# Spectra 0.20.2

- При первом контакте публичный ключ друга автоматически получается с авторизованного сервера и сохраняется локально (TOFU). Ввод отпечатка больше не требуется. Тот же механизм используется для личных сообщений, групповых сообщений и обмена сигналами P2P.
- Зашифрованная отложенная очередь повторно обрабатывается после появления ключа. Если ключ уже был сохранён и неожиданно изменился, автоматической замены нет: в окне ключей можно подтвердить новый ключ. Дополнительную ручную сверку отпечатков можно выполнить по желанию.
- Enter отправляет сообщение, Shift+Enter добавляет строку; Enter при вводе через IME не отправляет незавершённый текст.
- Чат оформлен как пиксельные игровые панели и слоты, время сообщений сокращено до часов и минут, поля и сообщения учитывают текущую тему.
- Исправлено распознавание открытия LAN-мира из Server thread. Добавлен запасной поиск через таблицы TCP IPv4/IPv6 Windows: рассматриваются только порты Java-процессов, запущенных этим лаунчером, затем выполняется настоящий Minecraft status ping. Чужие процессы и произвольные открытые порты не публикуются. Найденный порт записывается в активность и используется существующим P2P-мостом/обменом сборок.
- Отсутствующий LAN-мир больше не объясняется обязательной ручной сверкой ключа. Для мира всё ещё нужны разрешение на показ активности, открытие для сети и успешное соединение P2P. При строгом NAT может потребоваться TURN; сервер/инфраструктура TURN этим обновлением не добавляются.
- Автозапуск включён по умолчанию: HKCU Run, текущий пользователь, команда Spectra.exe --background. При входе в Windows окно и проверка обновлений не открываются. В фоне используется существующая система трея и друзей; при повторном фоновом запуске уже работающая копия не выводится на экран. Путь регистрации обновляется при обычном запуске. Настройки → Windows и фоновая работа позволяют отключить автозапуск.
- При общем градиенте новые панели чата/группы, настройки, предпросмотр и поля используют прозрачные оттенки общего фона, а не независимые сплошные фоны. Независимые градиенты отдельных зон остаются доступны.

## Важно для обновления

Обновите лаунчер у обоих игроков. Сервер Cloudflare от 0.19.0 менять не требуется. Установщик не изменялся.

Автоматическое доверие первому ключу не доказывает его подлинность при самом первом контакте с уже скомпрометированным сервером. Сохранённые ключи защищают от последующей незаметной подмены; отпечатки можно сравнить независимо. Приватные ключи остаются на устройстве. Сообщения, для которых приватный ключ уже утрачен, восстановить этим исправлением нельзя.

Проверены: реальное libsodium-шифрование и автоматическая расшифровка личных/групповых сообщений, повторная обработка отложенной очереди, блокировка изменённого ключа, Enter/Shift+Enter, переключатель автозапуска, разбор таблиц TCP v4/v6 и LAN-журнала, локальный TCP-мост, DOM и интерфейс Chromium. Код новых Windows-хелперов и App проверен компилятором с Windows Desktop references, все C#-файлы проверены синтаксически. Полная сборка WPF и проверка автозапуска/соединения двух Windows-компьютеров в этой среде не выполнялись.
