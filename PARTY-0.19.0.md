# Spectra 0.19.0 — Party и защищённые чаты

Это экспериментальная версия новой сетевой системы. До распространения среди игроков необходимо собрать лаунчер на Windows и проверить два компьютера в разных сетях. Полный Windows-клиент и реальный WebRTC через NAT здесь не тестировались. Реальный локальный TCP-мост, криптографические операции и серверные права проверены отдельно.

## Обновление

Party/LAN-мост и приглашения на текущий сервер в этой версии относятся к Java Edition. UDP/RakNet для Bedrock не реализован; уведомление о запуске Bedrock поддерживается.

1. Обновите сервер из `cloudflare-0.19.0.zip`. В папке сервера выполните `npm.cmd install`, затем `npm.cmd run deploy`. Скрипт deploy теперь сначала применяет миграции D1, включая `0006_party_chat.sql`. Новых внешних секретов для групп и чатов нет. Существующие Google-настройки, друзья и хранилище сборок сохраняются.
2. Соберите исходники Spectra на Windows обычным способом. Готовый JS-модуль libsodium включён в исходники; отдельно скачивать его при запуске не нужно. Для воспроизводимого обновления модуля: `npm.cmd install`, затем `npm.cmd run build:crypto`.
3. Оба игрока должны подключить Spectra Network через Google в профиле. Не путайте вход Microsoft для Minecraft и верификацию сети друзей.

## Как пользоваться

- В друзьях нажмите «Создать группу» и подтвердите предупреждение об IP. Вкладка «Группа» показывает участников и входящие приглашения. Приглашать можно только своих друзей. Приглашение действует семь суток.
- Группа сохраняется до удаления владельцем. Участники могут выходить из группы или отключать P2P, оставаясь участниками. Владелец может кикать, передавать владение и удалять группу. Максимум — 12 участников. Выход владельца возможен после передачи владения.
- «Ключ» возле игрока открывает сверку отпечатков. Сравните отпечаток с самим игроком лично или через отдельный доверенный канал и введите полученное от него значение. Это необходимо каждой паре устройств перед защищённой перепиской и P2P. Просто копировать значение с экрана в поле нельзя считать проверкой.
- После подтверждения ключей онлайн-участники автоматически создают WebRTC DataChannel с каждым другим онлайн-участником. Повторный запуск восстанавливает соединения, если P2P не был отключён. Отключение или полное закрытие программы не удаляет членство.
- В Minecraft Java откройте мир для сети. В «Группа → LAN-миры» появляются миры всех подключённых участников, в том числе несколько одновременно запущенных клиентов. Передаются название, версия, загрузчик, название сборки, картинка и число игроков, если ответил Minecraft status ping. IP показывается из статистики установленного P2P-соединения; если браузер его не раскрыл, показывается P2P. Число игроков не выдумывается: при отсутствии ответа показывается «нет данных».
- Для удалённого LAN-подключения лаунчер создаёт локальный TCP-порт `127.0.0.1` и передаёт поток через WebRTC. Порты не открываются на внешних сетевых интерфейсах. Входящая сторона может соединиться только с LAN-портом запущенного в лаунчере мира Minecraft.
- Для модифицированного мира предлагается выбрать совместимую установленную сборку или скачать сборку именно этого мира по P2P. Перед установкой показывается список файлов с возможностью выбора. Передаются только включённые `.jar` из `mods` и `.zip` из `resourcepacks`/`shaderpacks`: без сохранений, аккаунтов и конфигураций. Лимит — 512 МиБ, 2000 файлов, 64 МиБ на файл. Создаётся новая сборка, содержимое проверяется по SHA-256; имеющиеся сборки не перезаписываются. Несколько разных миров одного хоста используют разные снимки файлов. Мир должен оставаться открытым на время передачи. Подбирая уже установленную сборку, проверьте совпадение модов — одна версия загрузчика этого не гарантирует.
- «Чат» у друга открывает ЛС. В группе есть отдельный общий чат. Можно заглушить уведомления и очистить локальную историю конкретного чата.
- «Пригласить» отправляет приглашение на текущий сервер в ЛС или чат группы. Для личного приглашения в LAN-мир предлагается создать Party. Адрес и параметры приглашения внутри чата шифруются вместе с сообщением.

## Фоновая работа и уведомления

Крестик скрывает окно, процесс остаётся работать в системном трее. Повторный запуск открывает уже работающий экземпляр: это также предотвращает одновременную запись ключей и счётчиков двумя процессами. Полный выход — правой кнопкой по значку Spectra → «Выйти полностью». Новое приглашение в Party, запуск Minecraft другом и входящее сообщение показывают отдельное анимированное окно с вашим звуком `Release.ogg.mp3`. Кнопка уведомления и кликабельная запись в центре уведомлений открывают нужный чат, группу, проверку ключа или профиль. Заглушённые чаты не воспроизводят звук и не показывают всплывающее сообщение.

Окно уведомления использует Windows Topmost и не забирает фокус. Отображение поверх эксклюзивного полноэкранного DirectX-приложения не гарантируется; это нужно проверять на Windows. После полного выхода статус группы станет офлайн по истечении 45 секунд без heartbeat.

## P2P и NAT

По умолчанию используется публичный STUN `stun.cloudflare.com:3478`. Через строгий NAT, CGNAT и некоторые брандмауэры прямое соединение может не установиться. В «Группа → Настройки соединения» можно задать собственные ICE/TURN-серверы. TURN-сервис и его учётные данные в поставку не входят. При использовании TURN трафик идёт через него, а не напрямую. SDP/ICE доставляются через зашифрованный почтовый ящик.

Социальная БД не хранит открытый текст сообщений, адреса приглашённых серверов или открытый SDP/ICE. Однако Cloudflare обслуживает HTTPS-запросы и видит их сетевые адреса; STUN/TURN также видит необходимые адреса соединения. P2P по определению может раскрывать адреса участникам — поэтому требуется согласие.

## Что защищает чат

- Используется libsodium: Curve25519/XSalsa20-Poly1305 (`crypto_box`) и подписи Ed25519. Контекст, получатель, отправитель и группа входят в подписанный/зашифрованный пакет.
- Приватный seed хранится только локально, в хранилище Windows DPAPI для текущего пользователя, отдельно для каждого сетевого аккаунта и сервера. В Cloudflare публикуется только публичный ключ.
- При неизвестном или изменённом ключе расшифровка блокируется до ручной сверки отпечатка через независимый канал. Автоматической замены доверенного ключа нет.
- Офлайн-почта хранится на сервере до подтверждения получения, максимум 30 суток и 2000 пакетов на получателя. Локальная история — последние 2000 сообщений на сетевой аккаунт. Очередь отправки повторяется при доступности сервера. Часть групповой рассылки может доставиться раньше другой части.
- Счётчики и сохранённые идентификаторы блокируют повторную доставку. После удаления локальных ключей/переустановки устройства нужно заново сверить ключи; старые сообщения без старого seed не восстановятся. Одновременная работа одного сетевого аккаунта на нескольких устройствах не поддерживается этой версией.
- Это **не Signal Protocol / Double Ratchet и не MLS**. Прямой и обратной секретности уровня Signal эта версия не заявляет. При утечке локального приватного ключа старую переписку нельзя считать защищённой. Независимый криптографический аудит не проводился; сервер по-прежнему управляет членством групп и видит метаданные доставки.

## Проверки

Пройдены тесты прав Party, приглашений и доступа к почте; реальная libsodium-проверка шифрования, подписи, неправильного получателя, подмены ключей/контекста/данных и nonce; DOM-проверки с браузерной сборкой libsodium для офлайн-доставки, обязательной сверки, повторов, отправки и mute. Скомпилированы новые C# помощники с .NET 8 и Windows Desktop reference assemblies. На настоящих локальных TCP-сокетах проверены Minecraft status ping, число игроков, пересылка данных через два моста, подтверждения и очистка при отключении. Отдельно проверены блоки сборки конкретного мира, выбор файлов, запрет обхода пути, проверка SHA-256, создание отдельной сборки и соблюдение флага приватности. Полная WPF-сборка, реальные окна уведомлений, две удалённые WebRTC-сессии и запуск Minecraft требуют Windows-проверки.
