# Spectra 0.9.1

Адрес сервера друзей по умолчанию: https://spectra-friends.spectrafriends.workers.dev . Пустая настройка старой версии заполняется один раз; позднее адрес можно изменить или очистить самостоятельно.

Перед получением сессии друзей лаунчер выполняет тихое обновление Microsoft/Minecraft-сессии через существующий провайдер и проверяет профиль локально. Это устраняет передачу ранее сохранённого истёкшего токена. Серверный session token проверяется на принадлежность вошедшему UUID.

Worker версии 2 (/health) теперь различает HTTP 401, 403, 429 и временные ошибки Minecraft Services. HTTP 403 не маскируется под неверный аккаунт. Если после обновления появляется 403, локально обновлённый токен не смог пройти серверную проверку: требуется дальнейшая диагностика доступа Cloudflare к Minecraft Services, а не отключение проверки аккаунта. По старому общему сообщению определить исходную причину нельзя.

ОБНОВИТЕ ОБЕ ЧАСТИ: исходники лаунчера и src/worker.js в уже настроенном проекте Cloudflare. Сохраните свой wrangler.jsonc с действительным database_id, затем выполните npm.cmd run deploy. Существующая база D1 сохраняется; новых миграций нет.

Проверены JS syntax, frontend/theme/skin tests и серверная логика на SQLite (включая классификацию ошибок и запрет выдачи сессии при отказе Minecraft). Реальный аккаунт пользователя, сборка C# и Windows-запуск не проверены: здесь нет .NET SDK/Windows и пользовательского токена.
