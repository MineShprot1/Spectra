# Spectra 0.14.2

Добавлен закреплённый вариант «Последняя версия». Он запускает установленное обычное приложение Minecraft, предпочитая современный Windows/GDK-вариант; Preview и очень старые выпуски не выбираются. Если обычная игра не установлена, открывается Microsoft Store. После установки есть кнопка «Проверить и запустить». Это запуск установленной системной игры, а не гарантия, что Store уже обновил её до самого нового выпуска. Лицензию проверяют Minecraft / Microsoft Store; Spectra не получает отдельное подтверждение владения и не обходит права.

Для каталожных версий добавлено «Скачать пакет»: файлы сохраняются отдельно в %LOCALAPPDATA%/Spectra/bedrock/downloads без установки и замены игры. Разные версии имеют отдельные имена файлов и SHA-256 квитанции кэша. При необходимости установки отключён ForceUpdateFromAnyVersion. Если для той же идентичности пакета уже установлен другой выпуск, Spectra отменяет установку. Проверка выполняется и в C#, и непосредственно перед Add-AppxPackage в PowerShell.

Нельзя обещать независимый запуск нескольких официальных версий одной и той же идентичности через обычную регистрацию Appx. Эта версия сохраняет пакеты рядом, но не создаёт независимые игровые клиенты. Отдельные Preview с другой идентичностью допускаются, если Windows разрешает их установку.

Исправлена ошибка подхода к GDK: MSIXVC больше не передаётся в Add-AppxPackage, который предназначен для APPX/MSIX. Пакет сохраняется, а установка актуальной игры передаётся Store / Gaming Services. Полноценный установщик произвольных исторических GDK-пакетов в этой версии не реализован. Старые UWP APPX/MSIX по-прежнему передаются Windows, если нет конфликта версий. Проверки подписей, лицензий и системных зависимостей не отключаются. У Spectra нет собственной проверки лицензии старых версий, которую можно было бы отключить.

Подписи Preview и Windows 10 Edition исправлены в карточках, выбранной версии и быстром запуске. UWP помечается Windows 10 Edition, GDK — Bedrock Edition; Preview имеет приоритет. Галочка Windows 10 Edition сохраняет прежний фильтр очень старых выпусков.

Проверено компиляцией C#, тестами выбора обычной игры и защиты от замены, тестами названий и DOM. Настоящая установка и запуск Windows здесь не проверялись.
