# Spectra 0.16.4

- Удалены Minecraft Maps, NameMC, Skindex, MCPEDL, Parse API и встроенный браузер каталогов. В Java больше нет вкладки скинов. Сохранённые скины профиля и импорт Bedrock остаются.
- Категории в Обзоре выбираются выпадающим списком рядом с поиском, вместо выбора источников. Java: модпаки и карты; Bedrock: аддоны, скины, карты, текстур паки. Модпаки приходят из существующего объединённого поиска Modrinth/CurseForge; остальные списки из CurseForge. Отсутствующая категория CurseForge отображает ошибку доступности.
- Заголовок Обзор стоит выше выбора издания, в том числе для Java модпаков.
- Кнопка Сохранить настройки перенесена внутрь панели. Выход из общих настроек и настроек сборки проверяет изменённые поля: Отмена оставляет пользователя на странице с введёнными данными; Сохранить сохраняет и переходит на выбранную страницу. При неверных значениях или сбое сохранения переход не выполняется. Настройки внешнего вида и папки Bedrock, как раньше, применяются сразу.
- Сервер друзей исправлен по журналу Cloudflare: Minecraft profile/entitlements запрашиваются с redirect: manual. Ответы 3xx отклоняются без перехода и передачи токена на другой адрес.

Node-тесты сервера и лаунчера прошли, включая manual redirect, отказ на 302, категории и предупреждение настроек. Полная Windows C#/WPF сборка, реальный вход в Cloudflare и визуальная проверка на Windows здесь недоступны. Сервер необходимо развернуть из нового архива; новых миграций нет.
