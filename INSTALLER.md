# Сборка установщика
На компьютере разработчика нужны Windows, .NET SDK 8 x64 и доступ к NuGet.

Из корня исходников запустите:

```powershell
powershell -ExecutionPolicy Bypass -File .\BuildInstaller.ps1
```

Результат: `dist\Installer\SpectraSetup.exe`. Передавайте именно этот файл: он содержит файлы лаунчера и собственный .NET runtime. На компьютере получателя .NET устанавливать не нужно. Самому лаунчеру нужен Microsoft Edge WebView2 Runtime.

Установщик запрашивает права администратора, предлагает Program Files как родительскую папку, создаёт внутри выбранной папки `Spectra`, копирует лаунчер и создаёт выбранные ярлыки. Игровые сборки и аккаунты остаются в `%LOCALAPPDATA%\Spectra`.

В сборку не включаются локальные API-ключи и учётные данные. Установщик не скачивает приложение: версия лаунчера упакована при сборке. Self-contained single-file может извлекать нативные компоненты во временную папку .NET при первом запуске.

Текущий механизм автообновления Spectra компилирует исходники GitHub и поэтому отдельно требует .NET SDK 8. Это ограничение обновления, а не запуска установщика или лаунчера.
