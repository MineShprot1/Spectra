# Spectra 0.25.1

- Меню трея закрывается при скрытии системной панели значков, переключении в другое окно и нажатии Escape. Проверка работает только пока меню открыто.
- Аватарки в трее, друзьях и чатах формируются из настоящей текстуры скина. Для своего профиля используется активный скин, включая Ely, для друзей — Minecraft-профиль. Голова стороннего сервиса больше не подменяет их Стивом.
- Учитывается внешний слой головы. Добавлены ограниченный кэш, объединение одинаковых запросов и защита от подмены аватара запоздавшим ответом после смены аккаунта.
- Во все языковые пакеты добавлены 169 пропущенных строк: магазин, фильтры, темы, уведомления, друзья, трей, приветствие, ручная загрузка и сообщения об ошибках. Имена пользователей, названия сборок и сообщения остаются без изменений.
- Исправлен перевод стандартных заголовков гостевого профиля и группы. Добавлена проверка строк исходного кода и проверка английских экранов на оставшиеся русские подписи.
- Проверены пиксели головы и внешнего слоя, загрузка Ely-скина, выбор Minecraft ID друга, сохранение аватара при смене аккаунта и закрытие меню при скрытии панели трея.
