# Spectra 0.14.4

Исправлен подтверждённый пользователем формат исторических пакетов: выбранный выпуск 0.14.2.1 соответствует манифесту 0.142.1.0. Для выпусков 0.x используется объединение minor и build, затем revision, затем 0; для выпусков 1.x прежнее кодирование build*100+revision сохранено. Проверка манифеста допускает прямую запись и оба формата. Другой выпуск или ревизия отклоняется.

Последняя установленная игра не заменяется. Если в списке обнаружен другой установленный выпуск той же идентичности, кнопка предлагает скачивание отдельно и объясняет, что независимый запуск исторических клиентов пока не поддерживается. Проверки конфликта в C# и PowerShell сохранены, ForceUpdateFromAnyVersion не используется.

Сбой выдачи ссылки Microsoft — отдельная проблема сервиса; данный выпуск не обещает доступ к отсутствующим ссылкам.

Проверено компиляцией C#, тестом точного сообщённого формата, отклонением другой ревизии, основными тестами и DOM сценариями. Установка на Windows не проверялась.
