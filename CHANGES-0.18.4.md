# Spectra 0.18.4

Ползунок масштаба оформлен в пиксельном стиле Spectra: тонкая прямоугольная дорожка с заполнением, ступенчатый бегунок, подсветка граней и цвета текущей темы. Серый стиль стандартного Minecraft заменён. Расположение, диапазон и сохранение масштаба прежние. Проверены DOM-сценарии; визуальная проверка на Windows не выполнена.
