# Spectra 0.13.0

- В «Версиях» добавлен переключатель Java / Bedrock, фильтры Preview и Windows 10 Edition (выключены по умолчанию), выбор версии для быстрого запуска.
- Bedrock: обнаружение установленных приложений Minecraft, запуск через Windows, импорт локальных APPX/MSIX и установка выбранного пакета Windows с проверкой подписи самой Windows. При смене версии предварительно сохраните копии миров. Minecraft должен быть приобретён, вход Microsoft Store выполняется отдельно. Пакеты не включены в архив.
- Каталог обновлений Mojang содержит информацию о выпусках. Автоматическое скачивание всех исторических Bedrock-версий не реализовано. APPX/MSIX bundles и MSIXVC не импортируются. Установленная игра нового формата запускается через зарегистрированное приложение Windows.
- Карточки Modrinth/CurseForge открывают страницу проекта: описание, авторы, категории, даты, версии, галерея и установка. Работает для модпаков, модов, шейдеров и ресурс-паков. Доступность информации зависит от API. Описание HTML очищается от активного содержимого. Кнопка установки использует существующий подбор совместимой версии; список версий пока информационный.
- Steam: тёмная шапка, крупная навигация, боковая библиотека с поиском, более близкие к Steam карточки, зелёная кнопка запуска.
- Обновлены диалоги настроек, оформление аккаунта Spectra, всплывающие уведомления; добавлена панель истории уведомлений текущего сеанса.

## Проверки

Node: frontend-tests, appearance-tests, friends-tests, skin-tests, project-tests, bedrock-tests. Проверка синтаксиса JavaScript и XML проекта. Компиляция C#, визуальная проверка WebView2 и запуск/установка Bedrock на Windows в этой среде не выполнены.

## Сборка на Windows

Установите .NET 8 SDK и выполните из папки проекта:

```powershell
powershell -ExecutionPolicy Bypass -File .\Build.ps1
```

Проверьте переключение Java/Bedrock, установку официального пакета с резервной копией миров, работу быстрого запуска и открытие проектов из обоих каталогов. Не удаляйте BedrockBridge.ps1 из опубликованной папки: он копируется автоматически при сборке.
