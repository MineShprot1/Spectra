# Spectra 0.28.1

- Обычный и тестовый каналы проверяют явный `launcher-channel.json` из своих отдельных источников. Несовпадающий канал, тестовый суффикс в стабильном манифесте и устаревшая версия отклоняются. Служебный коммит без изменения номера больше не считается выпуском.
- Стабильная сборка принудительно собирается как stable. Тестовые параметры и счётчик убраны из публичного проекта; они остаются в `Spectra-Testing`. Перед заменой файлов проверяется совпадение версии собранного EXE с манифестом.
- В обычной версии сверху настроек находится плашка входа по одноразовому ключу. Его ввод автоматически запускает переход на тестовую сборку, без второго предложения обновления.
- Новые ключи `SPTEST2` создаются и регистрируются локальным Python-генератором, затем копируются в буфер. Каждый запуск создаёт другой ключ. В Cloudflare D1 атомарно фиксируется первое использование; повтор с другого ПК отклоняется.
- Сохраняется отдельная регистрация установки через Windows DPAPI. Тестовая сборка проверяет её при входе; формы ввода ключа в ней нет. Возврат на обычную версию сразу запускает установку и сохраняет регистрацию для повторного перехода без нового ключа.
- GitHub-токен больше не находится в ключах и в клиенте. Он хранится на отдельном Worker Spectra Network Dev, который предоставляет только чтение фиксированного приватного репозитория авторизованным установкам.
- Подготовлены Worker, D1, генератор, инструкции и архив для ручной загрузки в Cloudflare. До развёртывания сервера выдача и погашение настоящих ключей недоступны; незапущенный сервер не имитируется локальными проверками.
