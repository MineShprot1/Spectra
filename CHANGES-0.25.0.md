# Spectra 0.25.0

- Упрощены пиксельные иконки: меньше деталей, ровная сетка и единый размер.
- В «Обзоре» оставлен один видимый выбор типа контента, категории ограничены высотой окна, кнопки Java/Bedrock выровнены с поиском. Убраны миниатюры справа в блоке «В центре внимания».
- Окно скачивания получило компактную строку поиска и раскрывающиеся фильтры. Список и описание прокручиваются независимо; открытие проекта не меняет размер окна, закрытие сохраняет поиск и список. На узком окне описание занимает доступную ширину с возвратом к списку.
- Сторона установленного мода показывается как информация из метаданных, без ручного переключателя.
- Друзья остаются внутри лаунчера: свой профиль, поиск, группы «В игре», «В сети», «Не в сети», счётчики, сворачивание групп и открытие чата двойным нажатием.
- В меню профиля и трея добавлены имя, аватар, цвет активности и переключение видимости. Меню трея использует шрифт и палитру выбранной темы Spectra.
- Изменения оформления ограничены этими компонентами. Сохранены классическая оболочка и прозрачная область управления окном на экранах приветствия, обновления и входа.
