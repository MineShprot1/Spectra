# Spectra 0.20.5

- При запуске и перезапуске обновление регистрируется без диалога. Нижняя кнопка обновления остаётся доступной. Автоматической установки при запуске нет.
- Во время работы отдельный Windows DispatcherTimer проверяет новые коммиты каждые две минуты, в том числе при скрытом окне и без аккаунта друзей. Первый успешный результат создаёт исходную точку; последующие новые доступные коммиты вызывают предложение. Один коммит не объявляется повторно в текущем процессе. После перезапуска новая исходная точка создаётся без всплывающего окна.
- При видимом окне появляется диалог; если открыт другой диалог или выполняется вход, предложение ждёт. При скрытом/свёрнутом окне показывается настольное уведомление; нажатие открывает лаунчер и предложение обновления.
- Удалена кнопка «Отмена». В диалоге остаются «Обновить» и крестик закрытия. Закрытие не запускает установку.
- Таймаут Party больше не всегда сообщает о TURN: отдельно показаны отсутствие ответа друга, отсутствие собственных ICE-кандидатов, отсутствие кандидатов друга и неудача соединения после их обмена. Это диагностика, а не обещание исправить NAT. Для сетей, не допускающих прямой P2P, требуется настроенный TURN. Сам TURN-сервер этим обновлением не добавлен.

Тесты: npm test, npm run test:dom; нативный трекер обновлений (исходная точка, новый коммит, отсутствие повторов и тихий перезапуск), реальный TCP-мост и LAN-протокол. Проверен синтаксис C#12. Полная сборка WPF, фактические настольные уведомления Windows и связь двух удалённых Windows-компьютеров не проверены. Сервер и установщик не изменялись.
