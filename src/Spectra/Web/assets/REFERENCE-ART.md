# Reference artwork

`minecraft-launcher-cover.png` is the unchanged "Chase the Skies" launcher artwork
published by Mojang/Microsoft through the official launcher news feed:

- https://launchercontent.mojang.com/v2/news.json
- https://launchercontent.mojang.com/v2/images/MCVSummerDropSecondaryLauncher772x3501.png

Minecraft artwork belongs to Mojang/Microsoft. Edition SVG icons are original
vector illustrations. The bundled artwork is a fallback; a selected instance's
own banner takes precedence.
