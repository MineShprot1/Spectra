# Spectra Setup 0.17.9

Это исходники отдельного установщика, а не готовый EXE. Для сборки нужны Windows и .NET SDK 8.

Установщик использует оформление страниц завершения входа Microsoft и Google: тёмная карточка, фоновые свечения, логотип, пиксельные шрифты и светлая кнопка. При установке можно выбрать один из 13 языков лаунчера. Интерфейс установщика русский или английский; остальные выбранные языки применяются в самом лаунчере.

## Сборка отдельного проекта

Распакуйте готовый Windows x64 лаунчер со всеми зависимостями в отдельную папку, затем выполните в PowerShell:

```powershell
./BuildSetup.ps1 -LauncherFolder 'C:\Spectra-published'
```

Результат: `dist/SpectraSetup.exe` и отдельный архив `dist/Spectra-0.17.9-setup.zip`. Файлы лаунчера встраиваются в EXE; отдельная загрузка при установке не требуется.

## Сборка из полных исходников лаунчера

Запустите `./BuildInstaller.ps1` в корне полного проекта. GitHub Actions также собирает установщик: скачайте артефакт `Spectra-installer-windows-x64`, содержащий ZIP с готовым EXE.

Выбранный язык записывается в `install-preferences.json` рядом с установленным лаунчером и применяется один раз для этой установки. Последующие изменения языка в настройках сохраняются.
