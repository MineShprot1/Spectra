# Spectra Setup 0.28.2

Отдельный нативный установщик WPF для Windows x64, без WebView и фоновых эффектов размытия.

- 19 языков установщика; выбранный язык передаётся лаунчеру через install-preferences.json.
- Путь — точная папка установки, по умолчанию Program Files/Spectra.
- Независимые переключатели ярлыков рабочего стола и меню «Пуск».
- Отмена установки и восстановление заменённых файлов при ошибке.
- Установленная Spectra обнаруживается по стандартным путям, сохранённому пути или работающему процессу. При выборе своей папки проверяется и она.
- «Обновить лаунчер» всегда получает последний коммит main из MineShprot1/Spectra, проверяет канал stable и собирает эту версию даже при совпадающем номере. Тестовый репозиторий недоступен этому режиму.
- Обновление не зависит от встроенного обновления старого лаунчера. Перед заменой файлов Spectra необходимо закрыть.
- Для сборки используется установленный .NET SDK 8. Если его нет, загружается SDK от Microsoft в отдельный пользовательский кэш, с проверкой SHA-512. В первый раз это дополнительная загрузка и время сборки. Интернет и доступ к NuGet обязательны для режима обновления.
- Обычная установка использует встроенный пакет и не требует скачивания исходников или SDK. Аккаунты и сборки в AppData сохраняются.
- Журнал сборки обновления: %LOCALAPPDATA%/SpectraSetup-build.log. Кэш SDK: %LOCALAPPDATA%/SpectraSetup/sdk.

Сборка: ./BuildInstaller.ps1 (или -SkipLauncherBuild после публикации лаунчера).
Отдельная сборка: ./src/Spectra.Installer/BuildSetup.ps1 -LauncherFolder C:/published/Spectra.
Проверки: dotnet run --project tests/installer/Installer.Tests.csproj -c Release.
Проверка реального GitHub без замены установленного приложения: добавить -- --github.
Готовый файл: dist/Installer/SpectraSetup.exe.
