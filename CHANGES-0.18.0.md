# Spectra 0.18.0

Это обновление лаунчера. Отдельный проект установщика из прошлого диалога не изменялся.

## Аккаунты и запуск

- «Войти в другой аккаунт» открывает менеджер: аватары, имена при наведении, добавление Microsoft или офлайн-профиля.
- Лицензионные аккаунты сохраняются отдельно с конкретным идентификатором MSAL. Восстановление использует выбранный аккаунт и тихое обновление токенов. Временная ошибка восстановления не удаляет сохранённый профиль и не выдаётся за автоматический выход.
- После входа показаны приветствие, аватар, ник и анимированный индикатор. Такой же индикатор используется при загрузке страниц, диагностике и долгих RPC-запросах.
- Офлайн-профили создаются после лицензионного входа. Имя и ник скина Ely.by сохраняются; скины подключаются через локальный мост и официальный authlib-injector с проверкой SHA-256. Если Ely.by недоступен, игра запускается со стандартным скином.
- Офлайн-профиль использует сеть друзей выбранного сохранённого лицензионного профиля. Отдельная регистрация на сервере для офлайн-ника не создаётся. Официальный профиль Minecraft, плащи и серверы с проверкой лицензии для него недоступны.
- Кнопка с кубиком возле запуска сборки и в быстром запуске открывает несколько клиентов: один основной и до восьми дополнительных офлайн-клиентов. Имена и Ely.by-скины сохраняются, в том числе при уменьшении количества клиентов. У дополнительных клиентов отдельные папки игры; копируются моды, конфигурации, ресурсы, шейдеры и основные настройки. Миры не используются совместно. Суммарная память равна настройкам сборки на каждого клиента.

## Интерфейс и каталоги

- В настройках добавлен масштаб 65–150%, который сохраняется между запусками.
- «Мой Minecraft» перенесён под 3D-превью; элементы управления собраны компактнее. Добавлены счётчики сборок/скинов и действия для просмотренного профиля: надеть его скин либо такой же плащ, если он уже принадлежит вашему аккаунту.
- В Java-обзоре добавлена категория серверов Modrinth и страницы проектов серверов. Используется v3 API; реальный ответ каталога в текущей среде проверить не удалось. Статус и адрес показываются только если их возвращает сервис.
- Карты Java и весь поддерживаемый Bedrock-контент CurseForge открываются со страницей описания, галереей, версиями и загрузкой.
- Предпросмотр модов, ресурсов и шейдеров расположен слева от списка скачивания: список, запрос и прокрутка не заменяются страницей проекта.

## Сервер сборки

- Справа в редакторе сборки добавлен «СЕРВЕР СБОРКИ»: создание, запуск, штатная остановка, живая консоль, отправка команд, список файлов и редактор текстовых файлов до 1 МиБ. Перед сохранением создаётся копия `.spectra-backup`; редактирование доступно при остановленном сервере.
- Реализованы пути установки Vanilla, Fabric, Quilt, Forge и NeoForge. Перед созданием нужно принять Minecraft EULA. По умолчанию сервер привязан к 127.0.0.1:25565; отдельный выбор позволяет офлайн-клиентам подключаться к этому локальному серверу.
- Переносятся только моды со стороной «Серверный» или «Серверный и клиентский». Modrinth публикует сторону; для локальных Fabric/Quilt JAR читается манифест. Если сторона неизвестна, мод не переносится автоматически: выберите сторону вручную в списке модов. CurseForge не всегда предоставляет такую информацию.

## Краткая диагностика

- После завершения Java-игры появляется «Спросить ИИ».
- В настройках сохраните свой ключ Gemini: «Диагностика вылетов · Gemini». Ключ хранится локально через Windows DPAPI и не включён в этот архив. Также поддерживается переменная `SPECTRA_GEMINI_API_KEY`.
- Модель `gemini-2.5-flash-lite`: максимум 3500 символов очищенного журнала и 180 выходных токенов, thinkingBudget=0. Запросов в фоне нет. При штатном завершении без признаков ошибки или остановке через лаунчер ответ формируется локально без расхода токенов.
- Перед отправкой скрываются токены, пароли, длинные секреты, IP-адреса и имя пользователя в стандартном Windows-пути. Это автоматическая очистка, не гарантия удаления любой пользовательской информации. Полный лог и игровые файлы не отправляются.

## Проверки и ограничения

- Прошли `npm test` и `npm run test:dom`, включая новые сценарии аккаунтов, приветствия, нескольких клиентов, масштаба, профиля, сохранения списка рядом с предпросмотром и редактора сервера.
- Проверен синтаксис всех C# файлов. Реальные новые классы AccountPolicy, InstanceServer, CrashAssistant, OfflineSkinBridge и CommunityServers скомпилированы напрямую Roslyn вместе с Models/Network; зависимости игрового запуска в проверочном стенде заменены заглушками. Выполнены проверки UUID, ников, очистки/размера контекста, сторон модов и сохранения конфигурации.
- Полная WPF/CmlLib сборка не выполнена: MSBuild в этой среде падает при обращении к сведениям о процессе. Chrome для визуальной проверки тоже не удалось загрузить. Реальные входы Microsoft, Ely.by, сетевые каталоги, Gemini, несколько игровых процессов и серверные установки на Windows не проверены.
- В Windows CI добавлена `tests/Workspace.Tests.csproj` с полной ссылкой на проект лаунчера. Соберите на Windows через `Build.ps1` либо GitHub Actions. Не считайте этот архив проверенным готовым EXE.
