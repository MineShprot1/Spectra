# Spectra 0.16.0

Глобальное обновление после пользовательской версии 0.15.2. Следующий фикс — 0.16.1. Исходный загруженный архив имел метаданные 0.14.7; изменения выполнены в его содержимом.

## Изменения

- Последний Bedrock: «Обновить» открывает Minecraft Launcher; если он отсутствует — страницу minecraft.net/download. В Spectra появляется текст «Скачайте обновление через Minecraft Launcher». WinGet больше не используется для этого обновления. Переход на Minecraft for Windows выполняется по возможности через Windows UI Automation; если текущий Launcher не предоставляет доступный элемент этой вкладки, её нужно выбрать вручную.
- Модальные меню получили ограниченную высоту, прокрутку, затемнение фона, подписи для доступности, фокус и более удобные списки выбора файлов. Повторное открытие уже открытого диалога не вызывает showModal повторно.
- Java: отдельно скачать версию без запуска игры, затем ИГРАТЬ; удалить клиент версии с сохранением миров и сборок. Версия считается установленной для запуска Vanilla по его собственной папке, а не по файлам другой сборки.
- Bedrock: установка отделена от запуска; удаление зарегистрированной версии с резервной копией найденных UWP/GDK данных.
- Vanilla-друг не показывает «Скачать сборку». Подключение использует его версию Vanilla.
- Скин: защита от устаревшего асинхронного рендера, обработка потери pointer capture, запрет перехвата событий дочерними 3D-гранями. Плащ: исправлены внешняя и внутренняя текстуры.
- F11 и кнопка в настройках переключают полноэкранный режим; состояние сохраняется. Обычное развёрнутое окно ограничено рабочей областью монитора, чтобы не перекрывать панель задач.
- ОБЗОР переключает Java / Bedrock и категории. Java: модпаки, скины, карты. Bedrock: аддоны, скины, карты, текстур паки.
- Скины Java сохраняются в профиле; Bedrock — в выбранной папке загрузки.
- Карты Java устанавливаются из ZIP после выбора сборки/версии. Неустановленная базовая версия скачивается перед установкой карты. Архив должен содержать ровно один мир с level.dat; пути выхода за saves и ссылки запрещены.
- Bedrock сохраняет .mcworld/.mcpack/.mcaddon в список и открывает все сохранённые файлы при запуске последнего Bedrock. Импорт и его завершение выполняет Minecraft; Spectra не выдаёт запуск обработчика за подтверждённый импорт.
- ДОПОЛНЕНИЯ в версиях Bedrock показывает сохранённые файлы и установленные миры, behavior/resource packs из UWP и GDK хранилищ. Перед удалением установленного содержимого создаётся резервная копия. Файл Spectra и его импортированная копия — отдельные записи; удалите также сохранённый файл, если его не нужно импортировать снова.
- Друзья перешли на серверную проверку Minecraft-профиля и лицензии, без Google-аккаунтов. Инструкция миграции находится в серверном README.

## Каталоги и ограничения

CurseForge использует существующий API-ключ, определяет Bedrock game/category IDs через API и проверяет категорию скачиваемого проекта. Если категория (например, скины) не опубликована в API, показывается объяснение и ссылка на сайт.

Добавлены адаптеры публичных страниц Planet Minecraft, NameMC, Skindex, Nova Skin, MCPEDL, Minecraft Maps и Minecraft Inside. Это не официальные API этих сайтов: изменения HTML, JavaScript-рендеринг, CAPTCHA, вход и внешние страницы загрузки могут потребовать скачивания в браузере. Для этого предусмотрены «Открыть сайт» и «Импорт скачанного файла». Страницы Nova Skin и Minecraft Maps используются как вход в их каталоги; серверный поиск для них не гарантирован. Planet Minecraft Bedrock фильтруется по ключевому слову bedrock; совместимость окончательно проверяет игра.

Прямые загрузки разрешены только с доменов выбранного источника, с проверкой формата/размера, а для CurseForge — SHA-1, когда он опубликован. PNG-скины проверяются по сигнатуре и размерам. Поддерживаются одиночные скины PNG, не наборы Bedrock skin packs.

## Проверки

Успешно выполнены восемь наборов JavaScript-проверок лаунчера и шесть интеграционных тестов сервера с временной SQLite и имитацией Minecraft Services. Проверены смена «Скачать / ИГРАТЬ», отсутствие запуска при скачивании, подтверждённое удаление, Vanilla-друзья, новый путь обновления Bedrock, потеря захвата мыши, конкурирующий рендер скина и миграция друзей.

В среде подготовки нет .NET SDK и Windows; загрузка SDK заблокирована сетью. Поэтому C#-сборка, Windows/WebView2, Appx, реальный вход Microsoft и работа каталогов с живыми сайтами НЕ проверены. Chromium и jsdom недоступны, визуальные/DOM smoke tests не запускались. Сервер не опубликован. Перед распространением выполните Windows-проверки из VERIFY-0.16.0.md.
