# Spectra 0.20.0

- Полностью переделано оформление Party и личных/групповых чатов: заголовки, карточки участников, список миров, панели действий, отдельные пузырьки сообщений, адаптация к размеру окна.
- Анимации открытия, карточек и новых сообщений; фокус, черновик и положение прокрутки сохраняются при обновлении чата. Системное уменьшение анимации учитывается.
- Исправлен испорченный social.css из 0.19.0: в нём был посторонний текст вместо CSS.
- Фильтры загрузки модов: категория. Ресурс паки: категория, разрешение и особенности. Шейдеры: категория, особенности и требования — Калькулятор / Низкие / Средние / Высокие / Суперкомпьютер.
- Фильтры передаются как категории Modrinth с сохранением совместимости по версии/загрузчику. Для CurseForge используются точные соответствия категорий; если аналога нет, источник исключается из отфильтрованного результата с пояснением. Требования шейдеров — метки автора, не тест FPS.
- Предпросмотр дополнений ограничен шириной колонки: изображения, длинный текст, таблицы и код больше не расширяют окно. При узком окне колонки располагаются друг под другом.
- В общем списке модпаков добавлены FTB и Technic: поиск, страница описания, выпуски, просмотр манифеста и установка в новую сборку. Выбор источников не возвращён.
- FTB: публичный API, версии Minecraft/загрузчика из targets, минимальная память из манифеста, исключение serveronly, загрузка до шести файлов параллельно с проверкой SHA-1, лимит 8 ГБ на сборку / 512 МБ на файл / 10000 файлов.
- Technic: поиск Platform API, четыре официальных сборки при пустом поиске, ZIP и Solder, выбор выпуска, проверка MD5 при наличии, распознавание Forge через метаданные bin/modpack.jar. Старые/нестандартные игровые JAR без поддерживаемого манифеста отклоняются с объяснением; они требуют Technic Launcher. HTTP-источники не загружаются.
- Ошибочная установка удаляется, существующие сборки не перезаписываются. Чтение каталогов ограничено 20 секундами и размером ответа.
- Окна подключения и «Добро пожаловать» получили поэтапное появление и отдельную анимацию успешного подключения. Вращение индикатора загрузки сохранено.

## Проверка

`npm test`, `npm run test:dom`, переносимые тесты `tests/catalog/Spectra.Catalog.Tests.csproj` (реальный код каталога с тестовыми ответами HTTP), проверка синтаксиса всех C#-файлов Roslyn. Целевые проверки в настоящем Chromium: чат/Party, сохранение черновика, ограничение широких изображений/таблиц/текста на ширине 1200, 900 и 640 пикселей.

Живые публичные API FTB/Technic проверены на метаданных, поиске и манифестах. Полная установка многогигабайтной сборки и запуск Minecraft в Windows в этой среде не выполнялись. Сервер Cloudflare для этого обновления менять не нужно; используется сервер от 0.19.0. Установщик не изменялся.
