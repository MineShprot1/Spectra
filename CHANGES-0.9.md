# Spectra 0.9 — выделение, просмотр скриншотов и друзья

- Повторный клик по выделенному элементу снимает его выделение, сохраняя другие выбранные элементы. Ctrl добавляет элементы; рамка мышью сохраняется.
- Клик по пустому месту вне интерактивных кнопок/форм снимает выделение в текущем редакторе файлов сборки. Кнопки включения/отключения и копирования сохраняют выбор до выполнения действия.
- Скриншот открывается кнопкой «Открыть» или двойным кликом. В просмотре клик увеличивает изображение в 2,5 раза, перетаскивание перемещает его, следующий клик без перетаскивания уменьшает. Края перемещения ограничены изображением.
- Слева от аккаунта появилась кнопка друзей: список друзей и запросы, поиск ника, профиль, принятие/отклонение и подключение к опубликованному адресу игры.
- Настройки → Друзья Spectra: HTTPS-адрес общего сервера и публикация игровой активности. Сервер нужно развернуть отдельно из архива Spectra-Friends-Cloudflare.
- Присутствие и версия игры, загрузчик, мир/сервер, выбранный при запуске через лаунчер. Переходы внутри Minecraft автоматически не отслеживаются: это явно указано в интерфейсе.
- LAN-адрес можно сообщить друзьям вручную после открытия мира для сети. Проверяется локальная подсеть, VPN и подключение через Интернет не создаются.
- Новые каталожные сборки сохраняют проект и точную версию модпака. Друг может скачать эту опубликованную версию, если её нет. Локальные изменения/произвольные пользовательские сборки не передаются автоматически.

Архив содержит исходники. В этой среде нет .NET SDK/Windows: C# build, WebView2, авторизация и игра не проверены. Выполнены JS syntax, frontend/theme/skin tests и тесты Worker с SQLite и имитацией Minecraft Services. После развёртывания проверьте систему на двух Minecraft-аккаунтах.

Сборка как прежде: powershell -ExecutionPolicy Bypass -File .\Build.ps1
