# Spectra 0.28.0

- В «Windows и фоновая работа» добавлен неброский вход в режим тестирования по ключу разработчика и выход из него.
- Ключи ECDSA P-256 выпускаются локальным Python-скриптом: у каждого своя метка, идентификатор и срок действия. Секрет подписи остаётся на ПК разработчика; в лаунчере находится только публичный ключ проверки.
- Доступ к приватному `Spectra-Testing` предоставляется отдельным fine-grained GitHub-токеном с чтением только этого репозитория, внутри подписанного ключа. Сохранение — через DPAPI; интерфейс не получает токен или сохранённый ключ.
- Обновления используют отдельные репозитории и кэши. Переключение канала сбрасывает старое предложение обновления; запрос установки проверяет канал повторно. Ошибка приватного доступа не приводит к тихому скачиванию стабильной версии.
- Тестовые сборки получили отдельную нумерацию `0.1.0-test.N`, начиная с `0.1.0-test.1`. Версия отображается из метаданных сборки с сохранением суффикса.
- Добавлены генератор ключей, сборочный скрипт, инструкция `TESTING.md`, переводы и проверки подписи/подмены/срока, Python/.NET-совместимости, защищённого сохранения, разделения HTTP-авторизации и интерфейса переключения.
