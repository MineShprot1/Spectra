# Spectra 0.16.1 — диагностика друзей и каталоги с проверкой браузера

## Друзья

Причина ошибки на реальном Worker ещё не установлена: доступа к его журналам нет. В 0.16.0 необработанные ошибки D1, сетевые исключения и повреждённые данные скрывались под текстом Server unavailable.

Теперь `/health` сообщает `version: 9`, `schemaReady` и список отсутствующих таблиц. Ошибка отсутствующей таблицы/колонки возвращает `schema_missing` и инструкцию применения миграций. Отсутствующий DB binding сообщает отдельную ошибку; остальные ошибки получают incident ID. В журналах Worker есть событие `spectra_error` с причиной; токены редактируются. Схема базы и способ переноса друзей не менялись, новой миграции в этом фиксе нет.

Обновите сервер из нового архива, примените уже существующие миграции 0001–0004 и выполните deploy. Проверьте `/health`. Если `schemaReady: true`, но ошибка друзей сохраняется, запустите `npx.cmd wrangler tail`, откройте друзей и сохраните строку `spectra_error` для диагностики. Сам текст Server unavailable не доказывал, что миграция отсутствует.

## Каталоги

Ответ 403 от сайтов больше не выводится как непонятная ошибка .NET. Предлагается «Открыть в Spectra»: отдельное окно обычного WebView2, в котором пользователь может вручную пройти проверку сайта и открыть каталог. Кнопка «Показать список в Spectra» читает DOM текущей страницы и возвращает найденные проекты в ОБЗОР. Страницы не получают доступа к командам лаунчера или его файловым mappings.

Это интерактивный вариант, а не автоматическое решение CAPTCHA. Если сайт не поддерживает встроенный браузер или адаптер не распознаёт его разметку, остаётся обычный браузер и ручной импорт. Кнопка загрузки из карточки по-прежнему использует прямой HTTP-адаптер; защищённые скачивания могут требовать загрузки на самом сайте. Живые сайты и встроенный браузер в этой среде не проверены.

## Проверки

Семь серверных тестов проходят, включая отсутствующую миграцию и отсутствие DB binding. JavaScript-проверки проходят, включая кнопку повторного получения каталога через встроенный браузер. C#/WPF и реальная работа WebView2 требуют проверки на Windows; .NET SDK в среде подготовки отсутствует. Сервер не развёрнут автоматически.
