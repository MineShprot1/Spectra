# Spectra 0.14.3

Имена пакетов Windows проверяются без учёта регистра и приводятся к разрешённым каноническим именам. Ранее MICROSOFT.MINECRAFTUWP ошибочно отбрасывался, вследствие чего «Последняя версия» открывала Store вместо запуска установленной игры. Список дополнительно включает зарегистрированные Get-StartApps-ярлыки с точной идентичностью Microsoft Minecraft и суффиксом издателя 8wekyb3d8bbwe. Неудачное чтение одного манифеста не прерывает весь список.

При отсутствии установленного обычного Minecraft предлагается фоновая установка в Spectra через winget install, источник msstore, точный продукт 9NBLGGH2JHXJ. Нет автоматического перехода на страницу Store. Пользователь нажимает «Установить и запустить»; эта кнопка принимает условия источника и пакета WinGet, что указано в диалоге. После успешной установки приложение определяется снова и запускается. Обработка Store-инсталляции — до 45 минут, без интерактивного окна консоли. Нужно установленное приложение Microsoft App Installer / WinGet и доступ аккаунта Store к игре. Store может отказать в установке платного продукта или требовать вход; программа показывает код ошибки и bedrock/last-store-install.log. Есть отдельная кнопка открытия Store.

Прогресс выводится в нижнюю панель. Количество загруженных байтов и общий размер показываются только если WinGet действительно выдал их; иначе отображается неопределённый прогресс. Процент не имитируется. Прямой AppInstallManager не используется: Microsoft документирует ограничение доступа к этому API частной capability для приложений Microsoft.

При проверке UWP допускается прямое совпадение версии пакета с версией каталога или кодирование build*100+revision. Сравнение идентичности также не зависит от регистра. Для установки используется фактический номер из манифеста. Кэшированный пакет проходит такую же проверку. Если совпадения нет, сообщение содержит выбранный и фактический номера и имена пакетов; другой выпуск по-прежнему не устанавливается. Это расширение правил сопоставления, а не гарантия доступа ко всем историческим пакетам Microsoft.

Windows 10 Edition определяется старой категорией версии до 1.2, а не форматом UWP. Современный UWP — Bedrock Edition. Preview имеет приоритет. Исправлены карточки, быстрый запуск, сообщение о выборе и заголовок подтверждения. Старая ошибочная подпись в сохранённых настройках переопределяется по версии при отображении быстрого запуска.

Запрет принудительной замены существующей игры и ограничения MSIXVC из 0.14.2 сохранены: независимый запуск исторических клиентов не добавлен. Проверку лицензий не обходим.

Проверки: компиляция всех C# исходников, C# проверки регистра и сопоставления номеров, парсер WinGet-прогресса, 15 основных тестов, тесты интерфейса и DOM сценарий установки с последующим запуском. Реальные WinGet / Store / Gaming Services и запуск игры на Windows в этой среде не доступны.
