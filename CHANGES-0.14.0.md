# Spectra 0.14.0

## Bedrock из каталога

В «Версиях» выберите Bedrock Edition. Теперь это список выпусков, а не только установленное приложение: старые UWP и новые GDK. Preview / Beta и Windows 10 Edition выключены по умолчанию. Список показывает по 24 карточки; дополнительные открываются кнопкой «Показать ещё». Выбранный выпуск сохраняется в быстром запуске, где также есть фильтр Java / Bedrock / Сборки / Все.

Кнопка «Установить и играть» получает пакет с серверов Microsoft и передаёт установку Windows. Для UWP ссылка запрашивается через сервис Microsoft Update по ID выбранного выпуска; GDK использует точные MSIXVC-адреса Xbox CDN. Вручную искать и импортировать APPX/MSIX не требуется. Скачанные пакеты сохраняются в кэше и проверяются SHA-256 перед повторным использованием. UWP дополнительно проверяется по имени и версии в манифесте; подпись и права установки проверяет Windows. Выбранная версия после установки проверяется по зарегистрированному приложению.

Источники метаданных: [UWP](https://github.com/ddf8196/mc-w10-versiondb-auto-update), [GDK](https://github.com/LukasPAH/minecraft-windows-gdk-version-db). Игровые файлы скачиваются только с HTTPS-серверов Microsoft, не из этих репозиториев. Список кэшируется; при сбое источника используется сохранённая копия. Ссылки некоторых старых выпусков и бета могут быть недоступны или требовать дополнительного доступа Store. Загрузка каждой записи каталога не гарантируется.

Нужны Windows, лицензия Minecraft for Windows и вход Microsoft Store. Для новых GDK-версий нужны Gaming Services. Java-вход Spectra не заменяет вход Store. Перед переключением закройте Minecraft и сохраните резервные копии миров. Пока используется общий каталог игровых данных Windows: отдельные миры для каждого выпуска не создаются. Spectra не удаляет установленную игру перед сменой версии и не отключает проверку лицензии. Если Windows отклонит пакет из-за отсутствующих зависимостей или несовместимости, ошибка будет показана в лаунчере.

## Состав модпака

Страница модпака показывает выбранный выпуск, количество модов, шейдеров и ресурс-паков и вкладку «Состав» с поиском. Версию можно сменить; кнопка установки использует именно выбранный выпуск. Список дополнений разбит на категории, показывает название, версию, иконку, имя файла и признак необязательного дополнения, когда эти данные доступны. Страницу дополнения можно открыть поверх страницы модпака; для установки отдельно выбирается целевая сборка.

Состав читается из MRPACK/ZIP, без установки игровых файлов: манифест плюс overrides / client-overrides. Серверные дополнения, явно запрещённые для клиента, исключаются. Нераспакованные ZIP и папки ресурс-паков/шейдеров учитываются как отдельные дополнения, а не как все их внутренние файлы. Метаданные запрашиваются пакетами через API. Неизвестные проекты CurseForge показаны отдельно; при ошибке получения названий Modrinth остаются имена файлов. Дополнения, которые сам модпак скачивает только после запуска, заранее не определяются.

Архив предпросмотра ограничен 256 МиБ, манифест — 8 МиБ, число дополнений — 10 000. Предпросмотры кэшируются с ограничением примерно 512 МиБ на диске. Если автор запретил стороннюю загрузку архива, состав получить нельзя; запрет не обходится.

## Положение навигации

Настройки → Язык и оформление → Расположение навигации: сверху, снизу, слева, справа. По бокам используются пиксельные иконки и подсказки с названием раздела. Настройка сохраняется независимо от темы, входит в экспорт JSON и работает с боковой библиотекой Steam. Заголовок окна с кнопками закрытия и областью перетаскивания остаётся сверху.

## Проверки

- Полная компиляция C# прошла; после последних изменений повторная проверка всех исходников выполнена Roslyn с восстановленными ссылками WPF/WebView2. Нативный запуск Windows не выполнялся.
- Пройдены 15 основных C# проверок и тест реального парсера модпаков: категории, overrides, папки ресурс-паков, исключение серверных файлов, некорректные ID, структура SOAP-запроса.
- Все шесть наборов Node-проверок прошли.
- DOM-тесты прошли: навигация и переводы, выбор Bedrock в быстром запуске, устаревшие ответы при смене выпуска, ограничение длинных списков и независимость вложенных страниц.
- Живой каталог Bedrock вернул 504 записи. Живой предпросмотр Fabulously Optimized через Modrinth показал 46 модов и 3 ресурс-пака для проверенного выпуска.
- Выдача UWP-ссылки Microsoft в этой среде ответила HTTP 502. Реальное скачивание игровых пакетов, установка/переключение/запуск Bedrock на Windows и визуальная проверка в WebView2 остаются непроверенными. Получение Chromium удалось, но его запуск здесь заблокирован ограничениями среды.

## Сборка

```powershell
powershell -ExecutionPolicy Bypass -File .\Build.ps1
```

Скрипт собирает лаунчер, выполняет основные и новые C# тесты и публикует результат в `dist/Spectra`. Не переносите только Spectra.exe: рядом нужны Web, BedrockBridge.ps1 и остальные опубликованные файлы.

Для дополнительных проверок:

```powershell
npm install
npm test
npm run test:dom
dotnet run --project tests/features/Features.Tests.csproj
```

Опциональные сетевые проверки выполняются с `-- --live-pack` или `-- --live-bedrock`. Они не устанавливают игру; проверка Microsoft может завершиться ошибкой внешнего сервиса.
