# Spectra 0.20.4

- Текст настольного уведомления использует тот же minecraft.ttf, что и SpectraReading в веб-интерфейсе. WPF загружает его по внутреннему имени Minecraft Rus из папки ресурсов без установки шрифта в Windows.
- Согласование P2P использует trickle ICE: предложение/ответ отправляются сразу, найденные позднее ICE-кандидаты передаются отдельными зашифрованными сообщениями. Раньше параметры отправлялись однократно после ожидания максимум 8 секунд, а поздние кандидаты терялись.
- Кандидаты, пришедшие до ответа, ждут установки remote description. Идентификатор сессии защищает повторное подключение от запоздавших ответов и кандидатов предыдущей попытки.
- Через 45 секунд неудачного подключения показывается ошибка и кнопка «Повторить», вместо бесконечного пересоздания соединения. После обрыва установленного соединения даётся 15 секунд для восстановления. Повторить может любой участник: инициатор согласования выбирается автоматически. Закрытие старого канала не затирает статус ошибки; таймеры очищаются при отключении.

Обновите лаунчер у обоих участников. Сервер и установщик не изменялись. Некоторые NAT/брандмауэры не допускают прямое соединение: для них по-прежнему необходим собственный TURN в настройках Party. Это обновление не добавляет инфраструктуру TURN и не гарантирует соединение в любых сетях.

Проверены npm test и npm run test:dom, включая шифрование, сценарии offer/answer, поздние и отложенные ICE-кандидаты, отклонение устаревших сессий, таймаут, очистку таймеров и повтор. Код Windows-хелперов скомпилирован с Windows Desktop references; синтаксис C#12 проверен. Дополнительно предпринята проверка реального WebRTC в локальном Chromium: SDP согласован, но браузер в этой среде не выдал сетевых кандидатов, поэтому соединение подтвердить не удалось. Два Windows-компьютера в разных сетях и нативный шрифт уведомления здесь не проверялись; полная сборка WPF недоступна.
