# Spectra 0.18.1

- Исправлены размеры иконок и перенос меток CurseForge/Modrinth в каталоге модов, в том числе рядом с предпросмотром.
- Кнопка нескольких клиентов находится слева от «Играть» в быстром запуске и добавлена в редактор сборки.
- Обновлены общие диалоги, вход, приветствие, менеджер аккаунтов и блок «Мой Minecraft» под 3D-превью. Аватары имеют резервное изображение.
- Счётчик времени Java-версий, сборок и Bedrock сохраняется в playtime.json, автоматически каждые 20 секунд и при завершении. Дополнительные офлайн-клиенты не увеличивают счётчик.
- Общее время отображается в заголовках «Версии» и «Сборки», время сборки — рядом с датой создания, Java-версии — рядом с датой выпуска.
- При импорте Prism/MultiMC ZIP переносится totalTimePlayed из instance.cfg (секунды). Повторный импорт одинаковой истории не учитывается дважды. Экспорт также включает этот счётчик.
- В профиле «Активность» показывает общее время и три наиболее играемые сборки/версии. Друзья видят опубликованную активность с учётом настроек видимости.
- Запуск обычной версии не открывает редактор сборки. В профиле принятого друга отображается «Вы друзья».
- Обновлённый Worker показывает последнее посещение, сохраняет его после выхода и не удаляет историю посещения через сутки.

## Установка

Лаунчер: соберите исходники обычным способом. Для новых данных друзей обновите также сервер из cloudflare-0.18.1.zip: в его папке выполните npm.cmd install, затем npm.cmd run deploy. Новая миграция БД не требуется; существующие Google-настройки и база сохраняются. Установщик не изменён.

## Учёт времени и проверка

Время учитывается, пока открыт лаунчер. Время до этой версии неизвестно, кроме импортированной истории Prism/MultiMC. Bedrock учитывается при обнаружении запущенного процесса игры. Статистика хранится локально для этой установки лаунчера; сервер получает только общую сумму и три записи, если разрешена игровая активность.

Проверены Node-тесты интерфейса, DOM-сценарии, тесты Worker и компиляция/тестирование C# помощников с .NET 8. Полная WPF-сборка и фактический запуск игр требуют проверки на Windows.
