# Spectra 0.22.0

- Added a first launch welcome, Microsoft sign-in step, and animated theme picker with a live launcher preview. The onboarding is remembered after completion.
- Added CurseForge manual-download recovery for blocked mods, modpack components, resource packs and shaders. Choose files by category, open their CurseForge pages, verify downloads in the Downloads folder, and install matching files into the selected instance; other files can be skipped.
- Updated the launcher version to 0.22.0.
