# Spectra 0.14.1

Исправлено скачивание Bedrock: официальные HTTP-ссылки Microsoft больше не заменяются автоматически на HTTPS. Для загрузки игровых пакетов используется отдельный транспорт с точным списком разрешённых CDN: assets1.xboxlive.com, assets2.xboxlive.com и tlu.dl.delivery.mp.microsoft.com. Каждый адрес перенаправления проверяется; переход с HTTPS на HTTP запрещён. Cookies и авторизация не отправляются. Обычные загрузки лаунчера по-прежнему требуют HTTPS; проверка TLS-сертификатов не отключается.

HTTP не защищает передачу от подмены. Поэтому скачанный пакет передаётся штатному установщику Windows с проверкой подписи; лаунчер не обходит подпись, права Store или лицензию. Локальная SHA-256 служит проверкой целостности кэша, а не доказательством подлинности издателя.

При ошибке показывается цепочка причин, включая внутреннюю ошибку SSL. Диагностика сохраняется в bedrock/last-download.log в каталоге данных Spectra. Адреса загрузки из сообщений исключаются.

Проверено компиляцией C# и тестами загрузчика с имитацией ответа CDN: HTTP и HTTPS, разрешённое перенаправление, запрет посторонних хостов и понижения HTTPS, удаление временных файлов. Реальная установка пакета на Windows в этой среде не проверялась.
