# Spectra 0.14.6

Исправлена диагностика WinGet. 0x8A150014 — APPINSTALLER_CLI_ERROR_NO_APPLICATIONS_FOUND, пакет/сопоставленное приложение не найдено; это не доказательство отсутствующей лицензии. 0x8A15002B — нет применимого обновления. Неизвестные коды не трактуются как ошибка лицензии без данных журнала.

При отказе Store / WinGet возвращается отдельный статус, а не сообщение об успешном запуске. В диалоге можно открыть установленный официальный Minecraft Launcher, запустить текущую установленную игру без повторной попытки обновления либо обновить список и проверить снова. Официальный лаунчер открывается как отдельное приложение; обновление пользователь выполняет там. Автоматическое обновление через официальный лаунчер не реализовано, его приватные операции не имитируются. Источник Store / WinGet остаётся прежним, и причина отсутствия продукта определяется по last-store-install.log.

Официальный лаунчер ищется среди Get-StartApps с точной идентичностью Microsoft.4297127D64EC6 или Microsoft.MinecraftLauncher и издателем 8wekyb3d8bbwe, либо в стандартных каталогах Program Files. Если не найден, Spectra предлагает открыть его вручную. Windows Store не открывается автоматически.

Независимый запуск исторических пакетов не добавлен. Исследованный mc-w10-version-launcher запускает версии через ReRegisterPackage и удаление существующей регистрации той же семьи (RemovePackageAsync, вплоть до RemoveForAllUsers). Это не совместимо с требованием пользователя не затрагивать установленную последнюю версию. Спектра не заимствует этот механизм удаления, не переключает регистрацию системной игры, не перемещает миры и не отключает лицензионные проверки. Это ограничение текущей реализации, а не утверждение о принципиальной невозможности любого другого подхода.

Источники: https://github.com/microsoft/winget-cli/blob/master/doc/windows/package-manager/winget/returnCodes.md ; https://github.com/MCMrARM/mc-w10-version-launcher/blob/master/MCLauncher/MainWindow.xaml.cs .

Проверки: компиляция C#, тесты точных кодов ошибок, тесты DOM альтернатив при отказе WinGet, основные тесты интерфейса. Реальный запуск официального лаунчера и обновление через Windows не проверены в этой среде.
