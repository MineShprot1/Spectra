# Spectra 0.17.9

Установщик оформлен в стиле страниц завершения входа Microsoft и Google. Выбор языка лаунчера доступен на первом шаге; он применяется при первом запуске после установки и не перезаписывает последующие пользовательские изменения.

BuildInstaller.ps1 создаёт отдельный dist/Spectra-0.17.9-setup.zip с SpectraSetup.exe. В GitHub Actions добавлен отдельный артефакт Spectra-installer-windows-x64. Самостоятельный проект установщика содержит BuildSetup.ps1 и инструкции.

Проверки: npm test прошёл; XML файлов XAML, проекта и манифеста корректен. Компиляция .NET и визуальная проверка WPF не выполнены: в текущей среде нет .NET SDK и Windows.
